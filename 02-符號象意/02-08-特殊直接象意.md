## 原文重點整理

## 1. 個人用神臨十天干
「用神」指代表問測者本人（或所問之事）的符號。當用神與某天干
同宮（「臨」）時，書中給出對應斷語：

| 天干 | 用神臨此干的意涵 |
|---|---|
| 甲 | 有貴人相助 |
| 乙 | 優柔寡斷，也代表深思熟慮 |
| 丙 | 主有煩惱和亂子事發生 |
| 丁 | 會常有新奇的點子，出奇制勝 |
| 戊 | 主關於錢財上之事 |
| 己 | 主貪婪心較強，期待美好的前景 |
| 庚 | 說明遇到了阻力難題 |
| 辛 | 主出現了問題，或犯了錯誤、有不正確的行為 |
| 壬 | 主有經常性的問題發生 |
| 癸 | 主有經常性的大問題發生 |

## 2. 個人用神臨八神
| 八神 | 用神乘此神的意涵 |
|---|---|
| 值符（或年干、太歲） | 有社會背景、後臺硬、有人撐腰 |
| 騰蛇 | 為人狡詐多變或三心二意、拿捏不定、瞻前顧後 |
| 太陰 | 主思慮縝密、細膩、善於佈局策劃，亦代表背後有小人 |
| 六合 | 主外交好、善於逢合、利於與人合夥做事 |
| 白虎 | 主自身能力強，亦代表壓力大、受損失 |
| 玄武 | 主鬼點子多、腦子動得快，亦代表易上當受騙 |
| 九地 | 代表行動遲緩、亦錯過時機，或代表穩重保守、等待時機 |
| 九天 | 主志向遠大、胸有謀略，或好高騖遠、不切實際 |

|---|---|
| 天蓬星 | 敢說敢做、敢於冒險、善投機、亂中取勝 |
| 天任星 | 主勤奮積極、有韌性，但固執、缺乏開拓精神 |
| 天沖星 | 做事一鳴驚人、轟轟烈烈、不拖泥帶水，但缺乏謀略 |
| 天輔星 | 主有文化、有修養、善輔佐他人，從事文教事業 |
| 天英星 | 注重形象、注重名聲，過於急躁 |
| 天芮星 | 有問題存在，也好研究、發現問題，與宗教有關 |
| 天柱星 | 有獨撐局面的能力、力挽狂瀾的精神，亦主驚恐是非 |
| 天心星 | 主有管理能力、能屈能伸、有心計，做事善於謀略策劃 |

## 4. 用神的四種「特殊狀態」判斷規則
| 狀態 | 斷語 |
|---|---|
| 入墓 | 說明有力使不出（能力/資源受限，發揮不出來） |
| 逢空亡 | 主此人不在家，或有變動 |
| 逢擊刑 | 主此人有疾病傷災 |
| 逢門迫 | 主此人有受傷災之情事 |

## 5. 求財象義（依天干與九星分類）

| 辛 | 金銀、首飾、金屬裝飾 |

## 關鍵名詞解釋

| 名詞 | 說明 |
|---|---|
| 用神 | 排盤中選定來「代表問測者本人或所問之事」的特定符號（天干/八神/九星等） |
| 空亡 | 本節只載「不在家或有變動」的斷語；成立條件待第三章相關節次核對 |
| 擊刑 | 本節只載「疾病傷災」的斷語；成立條件待第三章相關節次核對 |
| 門迫 | 本節只載「受傷災」的斷語；成立條件待第三章相關節次核對 |
| 入墓 | 本節只載「有力使不出」的斷語；墓庫位置與判定方式待第三章補證 |

## 實務應用場景
- 這是「快速看盤」的操作口訣表：排出盤後先找到「用神」，
  再對照本節表格，直接讀出對這個人/這件事的初步判斷
  （有無貴人、財運、健康風險、是否在場等）。
- 求財象義表用來讀取盤面所指的財源或行業類別；這是作者的術數用法，
  不應單獨當作投資建議。

## 我的筆記／延伸思考
- 【可驗證類，且是全章「可操作性最高、命題最明確」的一節】
  這裡列出的規則幾乎都是**具體、方向明確、原則上可被證偽**的
  斷語，例如：
  - 「用神逢空亡＝此人不在家或有變動」——可以直接拿實際案例驗證
    （排盤當下此人是否真的不在場）；
  - 「用神逢擊刑＝有疾病傷災」——同樣可對照後續事實驗證；
  - 「開門入墓＝停產做不成」（見2-7）與「用神入墓＝有力使不出」
    彼此邏輯一致，形成一套內部連貫的「受阻」判斷系統。
  這類**條件明確、結果具體**的規則，是整本書中最適合優先做
  「準確率統計」的素材，建議之後讀到「10 佈局成功案例」時，
  逐案標記是否出現「空亡/擊刑/門迫/入墓」，並記錄事後的實際結果，
  長期累積後可以算出這幾條規則各自的命中率。
- 【方法論提醒】這幾條規則雖然「說法具體」，但仍然依賴前面
  「取用神」的正確性（見2-1筆記提到的結構性問題）——如果
  「用神」本身的選取規則不夠固定、允許事後調整，
  那麼即使規則本身命題明確，實際操作時準確率的統計意義也會被
  「選用神的彈性」稀釋。**驗證這套系統時，「用神怎麼選」和
  「用神臨某符號代表什麼」必須分開檢驗**，否則會混淆到底是
  規則本身不準，還是選用神的過程本身沒有固定標準。
- 求財象義表（甲乙＝木製品、庚＝金屬冶煉……）本質上是
  「五行類象」的延伸應用，屬於系統定義層，不是獨立的因果宣稱，
  但當它被拿來說「這盤顯示你適合投資某行業」時，就變成一個
  可以事後驗證「有沒有真的賺錢」的具體建議，值得記錄。
