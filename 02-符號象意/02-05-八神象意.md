## 原文重點整理

## 1. 八神是什麼：系統對「神／規律」的定義
作者對「神」的定義相對抽象且帶跨學科類比：
> 神是規律，是看不見的，就是大自然；神不會直接現形，
> 而是透過具體物體/事件顯現出來。

書中把「神」在不同學科的說法並列對照：天文學稱「黑洞」、
物理學稱「能量」、哲學稱「客觀規律」、佛學稱「佛法」，
現代人也稱「暗物質、電磁波」。並用一則寓言（信神者溺水時
拒絕了捕魚者和浮木的幫助，堅持等「神」親自來救，最後溺死）
說明作者的核心比喻：**神的作用是透過具體事物顯現**。整理時可把它
理解為八神要放回整個盤面合讀；但「八神不能單獨解讀」不是本節逐字
寫出的規則，因此不把這項理解當成原文明定條文。

## 2. 原始宮位圖與運行規則
書頁 103 的「八神原來配置宮位圖」其實同時疊列八神、九星、天干與八門，
不是只畫八神的單層位置圖；本檔不把它簡化成另一套固定宮位表，以免把
不同圖層混在一起。八神排列次序不變，運行採「陽順陰逆」。

書中另分天盤八神與地盤八神：天盤八神隨天盤九星的值符星每個時辰
轉動一次；地盤八神每十個時辰隨六甲值符轉動一次。作者明言本書實務
只使用天盤八神。

## 3. 八神所代表的「路」的意象（原書給的精簡對照）
這是書中少數用一句話講清楚、可直接套用的規則：

| 八神 | 對應「路」的意象 |
|---|---|
| 值符 | 漂亮高貴的大道 |
| 騰蛇 | 彎曲的路（變來變去） |
| 太陰 | 林蔭大道／看不到的地方／林間小道（暗喻陰謀詭計） |
| 六合 | 交叉路，多條路交會 |
| 白虎 | 路斷了、走到頭、窗子打不開（阻隔／鎖住） |
| 玄武 | 若隱若現、似有似無（遇到玄武要先聲明「我說了你也不信」） |
| 九地 | 穩定、低矮的路 |
| 九天 | 高速公路，高處的路 |

## 關鍵名詞解釋

| 名詞 | 說明 |
|---|---|
| 天盤八神 | 隨天盤九星的值符星每個時辰轉動一次的八神版本（本書實務只用此版本） |
| 地盤八神 | 隨地盤六甲值符每十個時辰才轉一次的八神版本（本書不用） |
| 陽順陰逆 | 八神的排列次序固定不變，但運行方向依陽遁（順行）或陰遁（逆行）而定 |

## 實務應用場景
- 幫盤面上原本中性的天干/九星/八門組合，加上一層「性質判斷」
  （例如同樣是「開門」，乘白虎跟乘六合，給人的感覺完全不同）。
- 用於快速判斷一件事的「氣氛」：是光明正大（值符、九天）、
  溫和合作（六合）、暗中進行（太陰、玄武），還是有衝突風險（白虎）。
- 「路的意象」對照表可直接用於問路況/交通類問題。

## 我的筆記／延伸思考
- 【定義類】八神固定宮位、陽順陰逆的運行規則、天盤/地盤八神的
  區分，是排盤的技術規則，屬於系統操作規範。
- 這節開頭那則「溺水拒絕捕魚者」的寓言，本質上是一個**哲學/信仰
  類比論證**，不是奇門遁甲的技術規則，比較像是作者用來說服讀者
  接受「符號系統的合理性」的修辭手法。值得留意：這類論證常見於
  各種玄學/信仰體系的入門說明，論證形式本身（神只透過載體顯現）
  並不能證明「奇門遁甲的八神對應規則」是準的，這是兩件事——
  即使接受「神透過事物顯現」這個哲學前提，也不代表「值符對應
  威嚴、白虎對應官司傷災」這組具體對應規則就是有效的預測工具。
  這是一個值得記住的**論證邏輯上的跳躍**，之後看到類似的哲學鋪陳
  時可以用同樣的角度檢視。
- 【可驗證類】「路的意象」對照表（白虎＝路斷了、九天＝高速公路）
  是相對具體、範圍窄的斷語，比起大範圍的性格描述更容易設計驗證
  （例如問路況時記錄「盤面顯示白虎乘天干」與「實際是否真的路斷/
  塞車」的吻合率），是本節中相對適合優先驗證的子項目。
