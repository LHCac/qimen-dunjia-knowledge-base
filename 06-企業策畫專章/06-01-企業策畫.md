## 原文重點整理

**企業預測模式的基本符號架構：**
- 「日干」代表企業，也代表「我」。
- 「時干」代表市場，也代表消費者（消費群體）。
- 「月干」代表競爭對手，或者是合作夥伴。
- 「日干的財」（我剋）＝工作平台、公司員工。
- 「日干的印」（生我）＝公司供應商，或幫助公司的貴人。
- 「日干的食神」（我生）＝公司的「產品」。
- 「日干的官鬼」（剋我）＝公司的「綜合管理能力」。
- 「剋」公司的宮位者，為「企業的瓶頸」。
- 八神代表企業的性質或內涵；天干代表企業的型態與作用；九星代表企業文化的內涵；八門代表企業的整體狀態。

**用人原則（八神與日干關係，決定人才對企業的作用）：**
用人原則：「有才有德重點使用，有德無才培養使用，有才無德慎重使用，無才無德禁止使用」。「德」看該人是否生日干宮（印），能幫助企業者稱有德；剋日干宮者較缺德。

| 八神 | 生日干宮（對企業有利） | 剋日干宮（對企業不利） |
|---|---|---|
| 甲（值符） | 直覺力強、領導力強、有威望、有管理能力，本身能帶來知名度 | 值符剋日干宮，此人不能用；應設法把值符宮移到能生比日干宮的位置 |
| 騰蛇 | 思想富有變化，用得好企業績效大起大落，用不好會把企業搞得亂七八糟 | 生我對我有利，剋我對我不利；騰蛇的人思想較陰毒 |
| 太陰 | 做事極為正面，產品做得精細 | 剋我則產品會出現瑕疵品；管人太嚴格會讓員工恐懼而影響產品完美度 |
| 六合 | 人緣好，會帶來很好的人緣 | 剋您時會組小集團與您對抗 |
| 白虎 | 生您時會帶領團隊一步步突破技術難關達成任務 | 剋您時能威脅您的未來，他就在您的對宮，會取代您 |
| 玄武 | — | 很會包裝、忽悠人，把廉價物品誇大功能賣高價；剋您就會騙您、對您不實在；生您則是騙外邊的人 |
| 九地 | 生您時很穩定、很實在、做事一絲不苟 | 剋您時很固執，只按自己意思做事，您改變不了他 |
| 九天 | 卓越的人，生您時會幫您出很多好想法達成目標 | 剋您時說的做的都不切實際、打高空，會帶來損失 |

**十天干的人與日干關係（依部門職能）：**

| 天干 | 對應部門 / 特質 | 生您（有利） | 剋您（不利） |
|---|---|---|---|
| 戊 | 財務、會計 | 對錢的概念好、忠實忠厚，幫您賺錢 | 會讓您虧錢 |
| 己 | 營銷、策劃部門 | 出好主意 | 出餿主意，不切實際 |
| 庚 | 技術部門（硬、逆商高） | 幫您處理棘手問題，有百折不撓精神，可阻擋不必要的問題 | 打擊您 |
| 辛 | 革新、改善產品及銷售模式 | 幫助您化險為夷 | 打擊您、出壞點子 |
| 壬、癸 | 流動、營銷、機械、物流部門 | 幫您增加銷售 | 非常被動 |
| 丁 | 訊息、宣傳、廣告、情報、調查部門（做事精細、頂尖人物） | 幫助宣傳、增加企業知名度 | 反宣傳 |
| 丙 | 文化宣傳（光明磊落、有話藏不住、很會反駁） | — | 讓您的領導力產生挫折 |
| 乙 | 藝術文化宣傳（本身有文化藝術素養） | — | 反宣傳 |

**九星的人與日干（企業）的關係：**

| 九星 | 特質 | 生您 | 剋您 |
|---|---|---|---|
| 天蓬星 | 做事雷厲風行，想什麼就做什麼，慾望大 | 幫您開創新事業 | 有可能取代您 |
| 天任星 | 做事任勞任怨，穩定 | 幫助您完成任務 | 凡事被動不積極 |
| 天沖星 | 執行力強（敏商）、也衝動 | 主動積極任事 | 因容易衝動帶來麻煩 |
| 天輔星 | 輔助老闆、企業的角色 | 幫助您成就事業 | 做事消極被動 |
| 天英星 | 適合宣傳工作 | 對公司幫助大 | 造成反宣傳效果 |
| 天芮星 | 適合教育部門 | 帶來正向人事管理 | 製造員工矛盾 |
| 天柱星 | 適合宣傳部門（喜歡動嘴巴） | 幫公司做正面宣傳 | 常給公司製造不必要的麻煩 |
| 天心星 | 適合管理階層工作 | 把公司管理得很好 | 讓公司管理亂七八糟 |

**八門的人與日干（企業）的關係——八門代表企業的整體狀態：**

| 八門 | 企業意涵 |
|---|---|
| 休門 | 流動性質，代表運輸、營銷、工廠生產線；思維不定，好時表現一般，壞時會更壞 |
| 生門 | 自我要求嚴謹，總想每天進步一點點，天天想往上發展 |
| 傷門 | 適合去討債、併購工作 |
| 杜門 | 搞技術的，適合研發技術部門工作 |
| 景門 | 適合宣傳、包裝工作、文宣工作 |
| 死門 | 適合做固定的工作與行業 |
| 驚門 | 做說的行業、播報員、演說家、講師，能在喧囂環境下工作（賣場、宣傳試賣會） |
| 開門 | 具開拓進取精神，適合業務市場開發工作 |

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 食神 | 日干所生者，此章對應「公司產品」 |
| 官鬼 | 剋日干者，此章對應「公司綜合管理能力」 |
| 印 | 生日干者，此章對應「供應商、貴人」，也是判斷人才有無「德」的依據 |
| 企業瓶頸 | 剋公司宮位的符號所代表的問題點 |

## 實務應用場景
- 為公司做人才任用診斷：依候選人在盤中對應的八神/九星/六儀，判斷其對企業是助力還是阻力。
- 分析企業內部各部門（財務、營銷、技術、宣傳）的人員配置是否得宜。
- 快速定位企業目前的「瓶頸」在哪個環節（供應商、員工、管理能力、產品）。

## 我的筆記／延伸思考
- 這一節本質上是把「奇門遁甲的符號系統」映射成一套「企業人才/職能分類框架」，功能上很像是一種另類的人格特質／職能測驗（如DISC、MBTI在企業管理上的應用），差別在於這裡的「測驗結果」是透過排盤（出生時間、問測時間）而非填答問卷取得。
- 這套對應表格本身邏輯自洽、描述具體（例如「玄武的人很會包裝、誇大功能」），讀起來很像對「話術型業務」或「浮誇行銷」人格的一般性觀察，容易讓人覺得「準」，但這其實也可能是「巴納姆效應」（Barnum effect）——這類描述放諸多數業務/行銷人才身上都部分適用。若要驗證，建議設計「盲測」：不知道對方盤局結果的情況下先描述其實際工作表現，再回頭比對排盤結果是否吻合，才能排除「先知道結果再找對應描述」的驗證陷阱。
- 「用才原則」（有才有德重用、無才無德禁用）這句話本身是務實的管理常識，跟玄學無關，是可以獨立於本書系統採用的通用管理原則。
