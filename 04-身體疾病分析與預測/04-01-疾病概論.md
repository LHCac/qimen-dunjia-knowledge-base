# 第一節 疾病概論

## 開篇聲明（重要前提）
作者自述不是中醫師；他說三次赴中國大陸學習期間，同學給了幾頁未署名的論病講義，
本章是在該資料基礎上經作者長時間整理、分類並加入實務經驗而成。
**書中明確聲明：這套方法是「為人診斷疾病的病因及位置，而不是幫人治病，
治病一定要看專業醫生」。** 這句話在第四章反覆出現，是理解整章內容定位的
關鍵前提——它自我定位為「輔助判斷／參考」，不是替代醫療診斷。

## 一、核心方法論：用神落宮綜合分析
道家陰盤奇門遁甲判病的邏輯是：先鎖定「用神」所在的宮位，再把該宮位內的
**天干、地支、八神、九星、八門、隱干**這幾層符號組合起來，交叉判讀身體
哪個部位、發生什麼性質的問題。

要學會斷病，書中先給出三組「天干對應臟腑／部位」口訣：

**（一）天干對應臟腑**
甲膽、乙肝、丙小腸、丁心、戊胃、己脾、庚大腸、辛肺、壬膀胱、癸腎臟。

**（二）天干對應頭面部**
甲頭、乙肩、丙額、丁齒、戊鼻、己面、庚筋、辛肋、壬脛、癸足。

**（三）天干對應軀幹部**
甲頭、乙項、丙肩、丁胸、戊肚、己腹、庚腰間、辛肋、壬腹部、癸四肢。

## 六～九、方法論補充要點

- **現代西醫的優勢**：作者肯定現代醫學在生理解剖與診斷儀器（聽診器、X光、
  CT、核磁共振等）上的精確與里程碑式進展。
- **病名對照問題**：奇門遁甲斷出的病名和中醫叫法常不一樣，但「跳不出陰陽
  五行的框架，跳不出九宮格這個總體框架」。
- **九宮格＝「其大無外、其小無內」的泛太極體系**：可以模擬從整個器官到細胞
  等不同尺度，用「比類取象」的方式舉一反三。
- **斷病思路：整體斷法 vs 單宮斷法**：
  - 傳統做法是只看「天芮星落宮」，書中明確指出**「這是不太正確的，最起碼
    有失偏頗」**——天芮星只有在「臨門迫、擊刑、入墓、空亡時」才代表真的
    有問題，否則不一定是病。
  - 正確做法：**先定座標**。當面問診時用「日干」定座標；電話問診時用
    「月干」；代問他人疾病時依六親關係定座標（問父母長輩用年干、問兄弟
    姐妹朋友用月干、問子女晚輩用時干）。
  - 「時干落宮」反映疾病目前狀態，需與用神落宮做生剋制化比較，綜合判斷
    性質、部位、內外、程度、病因、病理、發展狀況。
- **空亡轉宮法**：當用神所在宮位「空亡」或「伏吟」，代表原本反映的病已經
  轉移／變化，需要用「空亡轉宮法」查詢病情實際去了哪個宮位。
- **亞健康概念**：書中引用「現代醫學上叫亞健康，是健康與疾病的中間狀態」，
  並主張「在四柱之外的宮出現的問題可能就是亞健康狀態」，及時防範可避免
  轉化為病態。（**這段引用了「血液中一萬個癌細胞內屬健康」之類的說法，
  屬於作者自行詮釋，不是嚴謹的醫學數字，見下方延伸思考。**）
- **單宮斷不足取**：一個人可能同時有糖尿病、膝蓋不好、牙疼等多種問題，
  必須綜合分析各宮位才能看清楚，不能只鎖定一個宮位。
- **宮外隱干是查疾病的「引子」**：隱干代表導致疾病的導火索，需先從隱干
  分析原因，再從宮內分析細節，並用排除法一點一點篩選、避免「毫無邊際地
  瞎聯繫」。
- **法無定法**：強調靈活應用、理論與實際並重，不要生搬硬套。

## 常見疾病的判斷公式（原書第一個「十」；只論病不醫治）

書末強調「**只論病不醫治，醫治找醫生**」，並列出以下常見疾病的符號公式
作為範例（公式意指：宮位中出現這些符號組合，即視為該疾病的訊息）：

| 疾病 | 判斷公式（簡化摘錄） |
|---|---|
| 感冒 | 日干／時干臨丙丁或天芮星臨丙丁＝發燒；戊+壬或戊+癸＝流鼻涕 |
| 腮腺炎 | 戊己關係，坤宮／巽宮出現病星，日干時干加在戊上，臨巽坤宮上易得腮腫 |
| 肝炎 | 乙+丁、乙+丙＝肝炎；乙+庚＝肝硬化 |
| 糖尿病 | 必有水（壬癸代表血液）＋必有土（代表甜）＋必有天芮星，組合代表血液粘稠 |
| 痢疾 | 天芮星、日干、時干落坤宮或坎宮，又有白虎或壬癸代表肚子痛、腹瀉 |
| 肺結核 | 天芮星、日干、時干落乾宮或兌宮，有辛和白虎出現 |
| 瘧疾 | 乙+庚落離宮脖子強硬，日干時干出現戊+庚或癸+庚代表嘔吐 |

## 案例解析：27 年失眠的排盤示範
書末以真實案例示範完整流程：戊子年、辛丑月、乙丑日、辛巳時，空亡：申酉。

1. 先看日干乙丑無問題，時干與月干同宮也無問題；再看年干戊在兌宮，遇
   「景門門迫」，判定戊有問題。
2. 戊的問題結構：壬（血液）＋天芮（有問題）＋景門門迫＋酉（空亡）——
   因為空亡，需要「轉宮」，轉到坎宮看八分病因，原兌宮只占兩分病因。
3. 天心星＋驚門＝心驚膽跳、心悸；螣蛇＝頭暈；癸＝血液；己＝私慾念頭；
   壬+己＝失眠。書中特別註記「坎宮沒病斷病，病的狀況就小」。
4. 兌宮：戊+丁+壬+六合（合十）+天芮（觀音）+景門（漂亮）＝解讀為
   問測者西方擺放的觀音像（合手觀音）位置不當、且有破損裂痕（景門門迫），
   建議選卯日卯時燒香把西方的觀音移開／調整，即可改善失眠。

**這個案例是理解本書操作邏輯的關鍵示範：症狀（失眠 27 年）→ 排盤找出
「問題宮位」→ 把宮位的抽象符號意義（觀音、漂亮、合十）具體對應到現實
擺設物品 → 建議調整擺設位置。這一整套推理鏈條完全是象徵詮釋，沒有
獨立於解盤者主觀判斷之外的驗證步驟。**

## 我的筆記／延伸思考
- **可驗證性分級**：
  - 「規則層」（書上怎麼定義符號對應）：這是封閉的規則系統，本身邏輯自洽，
    但**規則的設定本身沒有說明依據**（為什麼乙落乾宮代表右腿神經血管？
    書中沒有給出可追溯的推導過程或統計基礎），屬於傳承下來的象徵慣例。
  - 「因果宣稱層」（斷出來的病＝真的病）：這是需要驗證的部分。書中舉的
    案例都是「先有已知症狀（如失眠 27 年）→ 回頭排盤找對應」，這種
    「後見之明式」的驗證方式（事後找解釋）本身無法證明系統的預測能力，
    因為任何症狀幾乎都能在龐大的符號組合表裡找到「對得上」的條目
    （這套系統本身就有幾百組排列組合，命中率的基線很難是隨機水準）。
  - 若真的想驗證，需要**盲測**設計：不告知排盤者當事人已知症狀，只給
    四柱資訊，看排盤結果與實際體檢報告是否吻合，且要有足夠樣本數與
    對照組（例如隨機猜測的命中率做比較）。目前書中沒有提供這類資料。
- **「亞健康＝一萬個癌細胞內都算健康」的說法**：這是作者自己的通俗化
  比喻，不是嚴謹的醫學共識數字，我在後續使用時不會把它當作事實引用。
- **最值得留意的一點**：書中反覆自我提醒「有病看醫生」「單宮斷不足取」，
  作者本身對這套系統的局限性有一定自覺，這點比起完全宣稱「準確無比」
  的類似書籍要負責任一些，但這不代表系統本身經過驗證，只代表作者態度
  相對謹慎。
- 下次讀到「斷病實務應用」清單（感冒、糖尿病等公式）時，可以整理成一份
  「可測試假說清單」：例如「當我知道某人有糖尿病時，回推排盤是否真的
  會出現『水+土+天芮』組合」，用自己身邊願意配合的案例做小規模檢驗，
  但要注意這仍然是後見之明測試，不是真正的預測測試。
