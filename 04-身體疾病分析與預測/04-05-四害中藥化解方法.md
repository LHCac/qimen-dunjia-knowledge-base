# 第五節 四害中藥化解方法

「四害」在本書體系中指「門迫」與「擊刑」這類代表破損、災病的凶格局。
化解邏輯延續第三節的「合」的概念——用地支相合的方式，找到對應的中草藥
組合來化解。

> 以下僅忠實整理作者所述的環境／民俗用法，不是醫療建議，也不是內服藥方。

## 一、門迫化解方（依八門分類，用地支合）

| 八門 | 化解用支 | 對應中藥 |
|---|---|---|
| 休門 | 丑合 | 山楂、山藥 |
| 生門 | 亥、天蓬星合 | 麥冬、桃仁 |
| 傷門 | 戌合 | 熟地、枸杞 |
| 杜門 | 申合 | 生地、益母草、百合 |
| 景門 | 未合 | 甘草、茯苓 |
| 死門 | 巳合 | 丹參、硃砂、紅花 |
| 驚門 | 辰合 | 黃耆、黃蓮、龍眼肉 |
| 開門 | 寅合 | 人參、川七 |

## 二、擊刑化解方（依天干分類）

| 天干 | 化解用合 | 對應中藥 |
|---|---|---|
| 戊 | 丑合 | 黃蓮、當歸 |
| 己 | 卯合 | 菟絲子、蘋果、桃仁 |
| 庚 | 乙合 | 佛手、鈎藤 |
| 辛 | 未合 | 山楂、乾薑、大蒜 |
| 壬 | 酉、丁火合 | 雞內金、紅花 |
| 癸 | 亥合 | 黑豆、熟地 |
| 辛金置換解四害 | — | 乾薑、細辛（用於急發性各種疼痛，書中類比西藥止疼片）、金銀花、枸杞、黃精子（適用於男女生育）、雞內金、菊花、大蒜 |

## 三、護體中藥（隨身與居家用）

| 用途 | 配方 |
|---|---|
| 隨身攜帶 | 紅花、硃砂、枸杞各取3克混合，用紅布包起 |
| 房子不適／壓迫感 | 紅花、硃砂、枸杞各取9克混合，放在家裡巽宮，書中稱可「控制一切靈異不被干擾」 |

## 實務應用場景
- 排盤找出問題宮位對應的門迫或擊刑天干後，直接查此表取得對應中草藥方。
- 護體中藥配方作為隨身或居家的「基礎款」，不需複雜排盤即可使用。

## 我的筆記／延伸思考
- 這張對照表本質上是一套**固定查表規則**：門迫/擊刑符號 → 地支合 →
  特定中藥組合。規則本身內部一致（每個符號都有固定的合支與固定配方），
  這部分屬於「書中定義的規則」，沒有對錯問題，就是紀錄下來。
- 「靈異不被干擾」這類宣稱屬於**無法檢驗的因果宣稱**（無法定義什麼算
  「被干擾」、什麼算「控制住了」，缺乏可否證性），我不會把這當作事實
  處理，純粹當作民俗記錄。
- 值得留意：多個門迫化解方都用到「硃砂」「紅花」「熟地」「枸杞」等重複
  出現的藥材，顯示配方設計上有一定的「核心藥材＋依情境微調」邏輯，這種
  重複模式如果之後有興趣，可以整理一份「跨配方藥材出現頻率統計」，看
  哪些藥材是「萬用款」、哪些是「特定情境限定款」，作為觀察這套配方系統
  內部結構的小練習（這是可以做、但仍然只是描述系統內部規律，不是驗證
  療效）。
