## 原文重點整理

**賣房子的方法：**
1. 時干逢空亡，要等填實或沖空時才能賣出。
2. 把房子落宮移到剋我的宮位上即可賣掉。
3. 戊空亡＝代表房子不值錢了。
4. 戊逢擊刑（震宮）、戊逢沖（離宮，甲子戊與離宮地支午相沖）。
5. 用沖的方式：戊在震佈兌宮沖震宮、戊在巽佈乾宮沖巽宮等。

**買房與賣房邏輯的差異：**
- 當初買房時是房子（時干）來生日干（我），這是好的購買格局；但住了一段時間後想賣掉，反而會因「房子戀我」（房屋捨不得離開你）而賣不出去，此時必須讓「時干」轉為剋我，才容易賣掉。
- 因此想賣房子時要重新起盤（因宇宙磁場會改變、三元九運也會改變）。若新起的盤中，時干落宮內有奇門四害＝容易賣掉；若時干仍是生日干，則需用「移星換斗」把宮位移到變成時干剋日干的狀態，才能賣掉。

**買房考量財丁兩旺：**
- 買房子要的是財丁兩旺，除了看時干要好外，還要看房子是否「帶財」：看「時干和戊」的關係，最好時干生日干（我）再生戊，或該房子時干落宮同時有「戊」，且沒有奇門四害來生「日干」最好。
- 現代人買房除了考慮財丁兩旺，也要考慮房子是否有增值空間（當財看）：此時看時干宮內是否有「戊」，若時干內有「值符」則易出官貴之人。要升官看值符與生門的關係（值符生生門）。

**值符與生門在陽宅上的角色：**
- 「值符」管整個盤，「生門」代表陽宅，代表整個房子狀況；時干則代表現在的狀況。房子本身好不好、是否能接到「龍脈與地氣」由值符決定，值符的重要性大於時干（房子）。
- 值符落宮若能來「生」生門，代表房子帶著旺氣滋養生門，象徵可能出官貴之人（值符）。
- 「生門」代表房子的整體狀態，房子要有生氣才會旺，旺了就能庇蔭住在裡面的人；若房子（時干）去生生門，則為「洩氣」，代表房子四周環境會吸走房子的旺氣；反之若值符來生生門，代表四周環境會不斷灌注旺氣給房子。
- 值符即「來龍」，生門即「向」，房子要能接住值符（來龍）的旺氣；若值符落宮有「傷門」則不好。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 移星換斗 | 一種奇門遁甲調理技法，透過改變符號的宮位配置來改變格局 |
| 財丁兩旺 | 財運與人丁（人口/健康）皆旺盛的理想狀態 |
| 值符 | 八神之首，代表整個奇門盤的主導能量，於陽宅中象徵「來龍」 |
| 來龍 | 風水學概念，指房屋背後的氣脈來源，此處對應值符 |
| 官貴 | 指能出仕途顯達、地位尊貴之人 |

## 實務應用場景

- 評估購入的房屋是否具備長期增值、旺人丁的潛力。

## 我的筆記／延伸思考
- 「買房要時干生日干，賣房反而要時干剋日干」這個對比很有意思，等於同一個符號組合在「持有階段」與「脫手階段」的吉凶方向剛好相反，這是體系內部自洽的邏輯設計，值得記錄但不必外推成一般性道理。
- 「值符大於時干、能決定房子是否接到龍脈地氣」這類敘述涉及較抽象、難以獨立驗證的概念（「龍脈地氣」本身缺乏可觀測定義），這部分建議歸類為「體系內部的解釋框架」，而非「可驗證的因果宣稱」。
- 相對而言，「時干逢空亡要等填實或沖空才能賣出」這種帶有時間預測性質的說法，理論上可以用「掛牌賣房的實際成交時間點」來回測，是這節中少數具備可驗證潛力的具體規則。
