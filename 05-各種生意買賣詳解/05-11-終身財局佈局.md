## 原文重點整理

**終身財局佈局六大條件：**
- 陰盤奇門遁甲個人終身財位佈局屬於「終身盤」，須以本命八字【日干】去佈局。
- 對於「適性、無病、健康」的財星，要給它放大，以達到催財效果。
- 終身財局如遇伏吟盤，則力量加倍。

**佈終身財局先後順序：**
1. 生門。
2. 戊的落宮。
3. 財星（九星）要得地或得時。
4. 判斷得地／得時的方式舉例：如天蓬星五行屬水，落在坎宮比和、震宮或巽宮財星生宮位為得地（可佈局）；在亥子月（水月）、寅卯月（木月）為得時（可佈局）。
5. 同時得地又得時最好；只有其中一項也可用。

**佈局吉祥物對照（依九星五行）：**

| 九星 | 五行 | 對應吉祥物 |
|---|---|---|
| 天蓬星 | 水 | 黑水晶或藍水晶 |
| 天任星 | 土 | 黃水晶球 |
| 天沖星 | 木 | 黃水晶柱 |
| 天輔星 | 木 | 黃水晶球 |
| 天英星 | 火 | 白水晶柱 |
| 天芮星 | 土 | 黃水晶球 |
| 天柱星 | 金 | 白水晶柱 |
| 天心星 | 金 | 白水晶球 |

**其他原則：**
- 長生、祿位以本命八字【日干】去尋找。
- 正財、偏財以本命八字【日干】去尋找。
- 佈局的宮位最後要生比本命八字【日干】。例如本命八字日干為「丁」落離宮（火），佈局宮位最好在震宮（木）、巽宮（木）、離宮（火）——木生火、火比和火，皆對日干有利。

**作者提醒（實務倫理）：**
- 由衷建議不要幫客戶佈終身局：一旦佈局一次以後就沒有生意了；更重要的是，幫客戶佈了終身局後，日後客戶遇到任何意外的事都會要求你負責，這樣沒有意義，也無法為對方負一輩子的責任。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 終身盤 | 以本命八字排出、用於一生財位規劃的固定盤局，區別於逐年變動的流年盤 |
| 得地 | 九星落於與其五行相生或比和的宮位 |
| 得時 | 九星落於與其五行相生或比和的月份 |
| 伏吟盤 | 特殊格局，此節中被描述為能使終身財局力量加倍 |

## 實務應用場景
- 為自己（而非他人）規劃長期、固定的財位擺設方案。
- 選擇吉祥物顏色與材質時的參考依據。

## 我的筆記／延伸思考
- 這一節的「吉祥物對照表」屬於典型的象徵對應規則（水晶顏色對應五行），這類規則在因果上難以獨立驗證——顏色/材質本身不太可能透過已知物理機制影響財運，這部分建議歸類為「信仰/象徵層面的操作」，而非「可驗證的因果宣稱」，除非未來想做長期主觀感受追蹤（例如記錄佩戴後的心理狀態變化）。
- 作者「不建議幫客戶佈終身局」這段話反而透露出一個務實/自我保護的考量（避免被歸咎責任），這其實是這本書中少數帶有「現實層面的執業倫理」思考的段落，值得特別標記，因為它跟玄學理論本身的對錯無關，是一種業務風險管理的建議。
- 「終身盤」概念意味著：這套系統認為存在一個固定不變、隨命主一生適用的財位配置。這是一個強因果假設（同一個佈局在數十年間持續有效），從科學驗證角度來看，這類「長期不變的固定效應」比「短期流年效應」更難設計對照實驗去驗證，值得記錄為高難度驗證項目。
