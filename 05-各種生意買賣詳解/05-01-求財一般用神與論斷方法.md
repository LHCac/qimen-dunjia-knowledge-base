## 原文重點整理

**基本用神設定：**
- 「開門」代表公司、工廠、店鋪；尚未開店時以此為用神。
- 若朋友邀約合作，時干宮出現騰蛇（虛詐不實）或玄武（陰險狡詐），則建議不合作。
- 獨資看「日干宮」；合夥看「日干＋時干宮」（時干宮視為合夥人）。日干宮＋時干宮大致可判斷七、八成的結果。
- 日干＝人／企業本身；時干＝財，可代表人、事、物。
- 「戊」＝本金，「生門」＝利潤，此二者是奇門遁甲求財的兩個主要符號。
- 「六合」＝事業合夥人、中間人、仲介人。
- 「生門和戊」所臨之星為「財星」，其落宮方位即為求財方向。
- 「生門」多代表一般房地產；「死門」代表地皮、不動產。
- 「景門」代表影視、旅遊；「天英星」代表表演事業。

**第三用神的概念：**
- 日干（第一用神）、時干（第二用神）為求財的固定基礎，之後再依問測者實際問題（如是否賺錢、能否成交等）選取「第三用神」。
- 與求財相關的第三用神主要是「戊」（本金）與「生門」（利潤）：利潤要能「生」本金，才算真正賺到錢落入口袋。
- 若日干有戊但逢「空亡」，代表缺乏資金；若戊逢「擊刑」，代表虧錢。

**生門與戊的四種關係（求財吉凶判斷核心）：**

| 組合 | 意涵 | 結果 |
|---|---|---|
| 生門生戊 | 利潤滋生本金，本金因利息越滾越多 | 賺錢 |
| 生門剋戊 | 利潤沒有增加反而消耗本金 | 賠錢 |
| 戊生生門 | 加碼投資，本金越大賺越多 | 投資對了 |
| 戊剋生門 | 利潤消失，代表生門「跑了」 | 選錯投資標的 |

**判斷賺錢與否的原則：**
- 日干宮與時干宮是求財總綱：日干剋時干＝我剋為財，可得財；時干剋日干＝我被剋，得財困難。
- 時干宮旺，來生或比合日干，求財有利；時干剋日干，對日干不利，強行投資易虧損。
- 日干生時干有兩種結果：若時干宮格局不好（逢奇門四害），會消耗、拖累日干而虧錢；若時干宮格局佳，投資仍會賺錢，但比較辛苦。

**已開店的補充要點：**
- 開門代表工作本身，即是已開店狀態下的用神。
- 時干＝員工、做事的平台；月干＝競爭者；年干＝時運、流年（年干看長久趨勢，時干看當下）。
- 問財運先看日干落宮（占約70%訊息），再看時干宮（工作平台）。
- 要往哪個方向求財，找「戊及生門」的落宮方位，即為求財方向。
- 賣貨：日干為人、時干為貨物、戊和生門為財；須分開判斷「貨是否賣得出去」與「賣出去是否賺錢」兩件事。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 日干 | 第一用神，代表問測者本人或企業本身 |
| 時干 | 第二用神，代表財、對方、貨物、市場、員工等，依問題而定 |
| 戊 | 本金／資本的符號 |
| 生門 | 利潤的符號，也代表一般房地產、事業整體發展狀態 |
| 六合 | 事業合夥人、中間人、仲介人 |
| 開門 | 公司、工廠、店鋪或工作本身的用神 |
| 死門 | 地皮、不動產；已開店時代表固定不變、停滯 |
| 景門 | 代表影視、旅遊，及景氣、市場行情好壞 |
| 空亡 | 代表「沒有」、缺乏、落空 |
| 擊刑 | 奇門四害之一，代表受傷、耗損、虧損 |

## 實務應用場景
- 判斷是否要與某人合夥做生意（看時干宮八神組合）。
- 判斷已開店的生意是否賺錢（看日干、時干、戊、生門的生剋關係）。
- 判斷該往哪個方位拓展業務或尋找財源（看戊、生門落宮方位）。

## 我的筆記／延伸思考
- 這一節本質上是建立一套「符號→現實對應」的固定映射表（日干=我、時干=財/對方、戊=本金、生門=利潤），這套映射規則本身是書中自定義的體系規則，沒有客觀驗證基礎，比較像是一種語言／框架設定，不是「可驗證的因果宣稱」。
- 真正可以做案例驗證的部分，是「當生門生戊時，實際投資是否真的賺錢」這類具體預測，可以之後蒐集多筆本命局與實際財務結果做back-test，看命中率是否顯著高於隨機。
- 「時干宮格局不好會消耗日干而虧錢，格局好但投資辛苦」這種說法有點「怎麼解都通」的味道（賺錢也對、賠錢也對，差別只在於過程順不順），這種雙向都能自圓其說的敘述在驗證時要特別小心「後見之明偏誤」。
