## 原文重點整理

### 一、作者的自我定位

- 作者把道家陰盤奇門遁甲的最高境界稱為「通靈」，並稱約 80% 與通靈有關。
- 原書明確表示這一概念「跟科學無關」，過程無法用科學印證，且最高境界難以用語言描述。
- 因此，相關敘述應分類為作者信仰與修行論述，不能當作科學、醫療、心理或因果證據。

### 二、修行與倫理語句

原書強調修心、得配其位、保持心靜、活在當下及反覆練習，也寫到下列主張：

- 奇門是多維、活的系統，修練者的心與意念會影響結果。
- 世界萬物可被理解為象，語言與符號可用來重組解讀。
- 書中有「沒有好壞、對錯」「說了就應事」及「攝住別人」等修辭。

這些語句可以作為作者哲學立場的文本材料，但不能用來免除錯誤責任，也不能合理化操控、羞辱、騷擾或傷害他人。

### 三、納甲對照

| 卦宮 | 納干 |
|---|---|
| 乾 | 甲 |
| 坤 | 乙 |
| 艮 | 丙 |
| 兌 | 丁 |
| 坎 | 癸 |
| 離 | 壬 |
| 震 | 庚 |
| 巽 | 辛 |

作者以此說明遁甲的「納甲」結構，並認為天干必須配合地支才有作用。

### 四、死門拆字與象的移除

- 原書把「死」拆作歹、一、匕，再把物件的形象與水、火等元素組合，示範移除被認為構成不利象徵的物件。
- 這是作者的字形聯想與行為風水案例，不表示移除物件會治療疾病、阻止事故或保證改變命運。
- 搬移宗教物品或他人物品前應先取得所有人同意；涉及大型、固定或電氣物件時也要注意結構與用電安全。

### 五、封神冊物與項鍊

- 作者把一段 28 顆珠子的項鍊對應二十八星宿，108 顆珠子則連到其所稱的 1080 局。
- 原書主張修練時配戴法器會「越走越靈」，這是信仰性說法，未提供可驗證的效力資料。

### 六、行道作法法器清單

書頁 533 清楚列出八項，沒有第九項缺漏：

1. 八卦墊。
2. 三清道祖神尊或神像。
3. 五雷令。
4. 香爐。
5. 印：封神用，可用三清道祖印或九天玄女印。
6. 定山向用的羅盤。
7. 桃木劍。
8. 朝簡。

整理稿原先稱第八項之後字跡模糊、可能仍有項目；第二輪查看原始頁後確認清單即止於八項，已刪除錯誤註記。
