## 原文重點整理

奇門遁甲講究天盤、地盤、人盤、神盤四層結構，四盤在九宮上都有固定的原始位置（陰遁陽遁排列位置相同，只有神盤方向不同）：

### 一、天盤（九星）
代表「天時」，即天體運動對地球和人類的影響。九星固定位置：
```
天輔星 天英星 天芮星
天沖星 天禽星 天柱星
天任星 天蓬星 天心星
```

### 二、地盤（九宮／洛書）
代表「地利」，即洛書九宮：
```
四巽 九離 二坤
三震 五中 七兌
八艮 一坎 六乾
```
口訣：戴九履一、左三右七、二四為肩、六八為足、五居中宮。

### 三、人盤（八門）
代表「人事」，即八門：休門、生門、傷門、杜門、景門、死門、驚門、開門。固定位置：
```
杜門 景門 死門
傷門 (中) 驚門
生門 休門 開門
```

### 四、神盤（八神）
指值符、螣蛇、太陰、六合、白虎、玄武、九地、九天。是古人在天人感應中發現、與九宮八卦有對應性質的八種神秘力量。神盤排列方式依陰遁逆排、陽遁順排而不同：
- 陰遁逆排：騰蛇/值符/九天，太陰/(中)/九地，六合/白虎/玄武
- 陽遁順排：九天/值符/騰蛇，九地/(中)/太陰，玄武/白虎/六合

### 五、道家陰盤奇門遁甲原始宮位圖
本書提供的原始宮位圖，除了八卦九宮、天干、地支、九星、八門、八神外，還額外標註：
- 六親角色（如巽宮長女、震宮長男、坎宮中男、離宮中女、艮宮少男、兌宮少女、坤宮老母、乾宮老父）
- 五行與人體對應（如巽震＝肝膽木、坎＝腎子宮水、離＝頭心火、坤艮＝脾胃土、兌乾＝呼吸食道／頭大腸心肺金）
- 時辰對應（每宮對應約 4 小時時段，如巽宮 07-11 時）

伏吟盤與全盤伏吟的判定，原書放在下一節書頁 160，故移至
[03-05 看盤、斷盤要領](03-05-看盤、斷盤要領.md)整理。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 天盤 | 九星所在的層次，代表天時／天體運動對人的影響 |
| 九星 | 天蓬、天任、天沖、天輔、天英、天芮、天柱、天心、天禽（固定於中宮） |
| 地盤 | 洛書九宮所在層次，代表地利／空間方位 |
| 洛書九宮 | 一坎二坤三震四巽五中六乾七兌八艮九離，是固定不動的空間座標基礎 |
| 人盤 | 八門所在層次，代表人事狀態 |
| 八門 | 休、生、傷、杜、景、死、驚、開，代表不同性質的人事狀態或行業性質 |
| 神盤 | 八神所在層次，代表神助／神秘力量對事件的介入 |
| 八神 | 值符、螣蛇、太陰、六合、白虎、玄武、九地、九天 |
| 原始宮位圖 | 本書作者提供的九宮盤基礎對照表，含五行、六親、身體部位、時辰等綜合資訊 |

## 實務應用場景

- 排盤時作為查表基礎：先定地盤（不動），再依局數排入天盤九星、人盤八門、神盤八神。
- 斷疾病時可對照原始宮位圖的人體部位（如坎宮對應腎、子宮）。

## 我的筆記／延伸思考

- 這節基本上是「符號定義表」，屬於系統的靜態架構規則，**沒有真假可言，只有記錯記對的問題**，適合直接做成查詢用的對照卡（見下方名詞總表）。
- 值得記錄但要注意查證的地方：洛書九宮排列（戴九履一等口訣）與八卦後天方位是傳統易學共識，這部分跨書籍、跨門派應該高度一致，可以之後找其他奇門遁甲或風水書籍交叉核對，確認本書排法沒有 OCR 誤植或作者筆誤。
- 「五行與人體對應」（如坎宮＝腎）雖然源自中醫五行臟腑理論，這部分本身在中醫學界也有其理論脈絡與臨床觀察基礎，但要注意：這與「用奇門遁甲盤斷病」是兩件事——中醫五行臟腑對應有其獨立的理論與經驗基礎，但「用起局時間對應的宮位符號來斷特定病症」則是額外一層推論，這層推論的準確性才是真正需要案例驗證的部分。
