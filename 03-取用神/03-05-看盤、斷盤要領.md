## 原文重點整理

### 一、天地盤天干的陰陽故事
天盤天干為陽，地盤天干為陰，兩者組成一對陰陽，彼此「矛盾、對立、又統一」，合為一體描述一個完整故事。日天干代表問測者本人；地盤天干代表問測者現在碰到的事情及內心想要的問題所在。

### 二、入手式（開盤第一步）
開盤要先看的，就是「入手式」：看天盤天干下面的地盤天干是什麼，就能知道問測者會碰到或已發生什麼事情。

十天干基礎象意（希望／機會／困境系列）：
- 乙丙丁都代表希望、機會、光明：乙＝曲折的機會，丙＝會出亂子但仍可達成目標，丁＝最直接的機會
- 戊＝代表錢
- 己＝代表陷阱
- 庚＝阻隔
- 辛＝錯誤
- 壬、癸＝都是動（走），代表困境

### 三、看盤基本要領——起手式（單宮斷）範例
書中以一個範例示範完整解盤邏輯（乾宮：值符/天蓬星/壬（天盤）/戊（地盤）/傷門）：
1. 戊代表跟錢有關（戊是大地、陽土、跟本金有關），看戊的符號狀態判斷有沒有錢。
2. 生門代表利潤（戊土生出的錢），戊若入墓表示錢沒了。
3. 日干地盤天干有戊，代表問測者問的問題跟錢有關。
4. 宮內有「天蓬星」——天蓬星代表搶、強盜，被稱為「黑社會老大」，膽大妄為，代表投資的錢被汙（被搶）了。
5. 財碰到天蓬星就破財，代表錢被合夥人搶走（掏空）。
6. 碰到「傷門」代表現在傷心的狀態（八門代表人的狀態）。
7. 值符代表「原告」，代表打算要告對方（測官司時值符為原告，談借貸時值符為出借方）。
8. 整合描述：問測者碰到跟錢有關的事情，錢入墓沒了，因碰到天蓬星錢被合夥人搶了吞了，現在很傷心，正準備積極打官司告他要把錢要回來；宮位在「乾宮」（乾為天，居高臨下、主動積極），代表他正積極準備行動。

### 四、其他看盤原則
- 落宮符號看懂，就能知道問測者現在的處境及問題癥結，並可對症下藥處理。
- 盤是死的，人是活的，同一盤可以看很多事情，解盤功力不同、結果不同。
- **道家陰盤奇門不談吉凶**：吉凶是人心所定，喜歡的就是吉、不喜歡的就是凶（貪嗔癡）。
- 看盤要先看對方是誰（地盤天干代表什麼），例如「它是老虎、我是貓」則對我不利，相反則對我有利，兩者合起來變成完整故事。
- 「陰陽學」需要有一樣東西跟自己形成矛盾對立（如問顏色用黑白對立、問水溫用冷熱對立），這個宮位要走向下一個宮位怎麼走，取決於問測者想知道什麼。
- 若問未來（如公司業績會不會好），依時間分陰陽：現在宮位為陽、未來宮位為陰，此時可以用「翻宮」。翻宮後的宮位和用神宮位（日干）產生陰陽對立，以日干為太極中心向外擴張。

### 六、動處與特殊狀態（書頁 161）

作者說宮內符號可視為問測者不同面向；宮位若見奇門四害，代表該方向
受阻或狀態不佳。原書另列幾個需要優先留意的「動處」：

- 馬星：代表異動。
- 空亡：代表事情將有轉變。
- 上四綱：日干或時干落在與所問事情直接相關的四綱位置。
- 偏離目標太遠：作者提醒解讀時不要亂射、不要離題。

原書同頁另載「久病逢空則死、新病逢空則好，沖空則應」；這是作者的
術數斷語，不是醫學判斷，不能據此診斷、延誤就醫或調整治療。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 入手式 | 看盤第一步，觀察天盤天干下方地盤天干，判斷問測者遇到的事情 |
| 天盤天干 | 代表「已浮出水面」的、外顯的性格或狀況（陽） |
| 地盤天干 | 代表問測者現正遭遇、內心想要的問題所在（陰） |
| 隱干 | 事情發生的遠因或近因，可另外打開查看細節 |
| 單宮斷 | 只針對一個宮位內符號組合進行解讀的斷盤方式 |
| 翻宮 | 為了看未來（陰面）而另參相應宮位的技巧；本節未給出完整固定對照表 |
| 伏吟盤 | 開盤後八門、九星等仍在原始位置的盤局 |
| 全盤伏吟 | 伏吟之外，天地盤天干也相同的狀態 |
| 天機在動處 | 作者用來提醒優先觀察馬星、空亡等變動訊號的口訣 |
| 吉凶由心 | 作者主張道家陰盤奇門不預設吉凶標準，吉凶取決於問測者主觀好惡 |

## 實務應用場景

- 拿到一個盤時，先看日干宮的「入手式」（天盤天干對應的地盤天干）。
- 判斷財務問題：看戊（錢）落宮狀態，搭配生門（利潤）、天蓬星（破財、搶奪）等符號。
- 判斷官司／借貸糾紛：留意值符（原告／出借方）角色。

## 我的筆記／延伸思考

- 這節示範的「解盤敘事」（乾宮案例）非常具有故事說服力，但要注意：**這是「事後合理化」式的敘事構造**——先確定了「戊代表錢」「天蓬代表搶」「傷門代表傷心」等固定符號意義，再把它們串成一個連貫的故事。這種敘事結構本身邏輯自洽，但並不代表它對應到真實世界的因果關係；任何一組符號組合，經過同樣熟練的敘事技巧，幾乎都能編出一個「說得通」的故事，這是命理／占卜類系統常見的「巴納姆效應（Barnum effect）」風險，值得特別留意。
- 「道家陰盤奇門不談吉凶，吉凶是人心所定」這句話某種程度上頗有見地（避免簡化為宿命論），但也讓整套系統更難被證偽——如果吉凶隨解讀者主觀認定，就很難設計客觀的準確度檢驗方式。
- 可驗證的部分：如果之後要測試這套系統，應該鎖定**具體、可核對的客觀事實類斷語**（例如「錢被合夥人A搶走」「即將提告」這類具體事件），而非抽象的吉凶好壞判斷，這樣才有機會做事後對照。
