## 原文重點整理

1. **預測原理**：奇門遁甲能預測未來、知曉過去、甚至改變事物發展態勢，關鍵在於「來人起心動念的問測時間」。透過精準的時間計算得知氣場的流行運轉，進而推算氣場碰撞產生的作用。
2. **四大關鍵要素**：道家陰盤奇門遁甲把「天時、地利、人和、神助」視為主要影響人類能量場的因素，並與時空結合，建立一個模擬宇宙全息場的象數模型。
3. **科學性主張**：作者主張奇門遁甲是把宇宙立體模型「投影縮」在一張八卦九宮盤上的「時空立體盤」，本質上結合了人體、天體、地球運動規律等知識。
4. **學習要件**：要學會奇門遁甲，需精通八卦、九宮、星象、曆法。作者特別強調「評斷一個國家是否文明，就是以該國曆法進步與否來評斷」，曆法即掌握宇宙、星空、地球運轉規律的科學。
5. **應用規模**：奇門遁甲盤可以模擬國家、地球、戰爭、企業、個人，且九宮中任一宮都可再分九宮細看，可用來問感情、工作、事業等各類問題。
6. **內容五大分類**：
   - 符號系統：奇門較重視形、音、義的象意
   - 用神系統：如何依問題選定代表用神
   - 理則系統：斷事的邏輯規則
   - 處理系統：拆、補、移（拆和補只用在有四害的宮位，移則是九宮同時轉動，即「移星換斗」）
   - 分類預測：針對人、事、時、地、物的分類預測方法
7. **斷事二大系統**：
   - 宮卦系統：八卦、九宮、八神、九星、八門、隱干。其中八門、九星有固定卦位與本質（如天蓬、休門對應坎宮水性；景門、天英星對應離宮火性、發光發亮）。八卦本身在奇門中主要用於：(1) 斷落宮含意（日天干落宮代表問測者客觀環境因素）；(2) 斷疾病時需搭配八卦及宮位判斷。
   - 神煞系統：八神系統，每個宮位符號都會搭配不同的神出現，書中提到要真正學會奇門遁甲，還需學會「法術奇門＝踏罡步斗」並修練自身能量，否則佈局難以成功。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 時空計算器 | 作者對奇門遁甲的定性：藉時間精準計算得知氣場運轉，推算氣場碰撞後果的模型 |
| 起心動念 | 問測者產生疑問的那個「時間點」，是開盤起局的依據 |
| 天時地利人和神助 | 奇門盤模擬的四大能量來源：天盤（天時）、地盤（地利）、人盤（人和）、神盤（神助） |
| 象數模型 | 用符號（象）與數字排列（數）模擬宇宙全息場的模型 |
| 符號系統 | 奇門盤中各類符號（天干、八卦、八門、九星、八神等）及其形音義象意 |
| 用神系統 | 依問題性質選定代表相關人事物的宮位／符號的規則 |
| 理則系統 | 斷事所依循的邏輯規則 |
| 處理系統 | 拆、補、移三種調理／改運手法 |
| 宮卦系統 | 以八卦九宮八神九星八門隱干構成的靜態符號對應系統 |
| 神煞系統 | 以八神為核心、需搭配法術修練（踏罡步斗）的能量系統 |

## 實務應用場景

- 起局前先確認「問測時間」是核心操作依據，時間錯誤會導致整個盤面失去參考意義。
- 學習路徑規劃：需搭配八卦、九宮、星象、曆法等基礎知識，而非只背誦斷語口訣。

## 我的筆記／延伸思考

- **「起心動念的問測時間」是整套系統的核心假設，也是最難驗證的一環**：這預設了「同一時刻起局，會準確對應到問測者當下處境」，這是一個因果宣稱，理論上可以透過「盲測」方式驗證——例如同一時間找不同背景的人問不同問題、對照解盤與後續實際結果的吻合度，用統計方式檢視命中率是否顯著高於隨機猜測。這是我認為之後最值得系統性收集案例來驗證的部分。
- 「奇門遁甲其實是很科學的」這類敘述屬於**類比式論證**（把陰陽五行、天體運行類比為「科學」），並非嚴謹科學方法論意義上的「科學」，兩者概念不能直接劃等號，閱讀時要留意作者用詞的修辭效果。
- 「以曆法進步與否評斷國家文明程度」這句話本身在天文學史脈絡下有一定道理（曆法確實反映一個文明的數學與天文觀測能力），但用來佐證奇門遁甲的有效性則是不相干的推論（曆法的科學性不等於建立在曆法上的占卜術的科學性），這是需要留意的邏輯跳躍。
