## 原文重點整理

### 一、奇門四害表與基本原則
道家陰盤奇門遁甲就是一個「找四害、處理四害」的過程，像幫病人診病治病一樣：先找出病，描述病況，再來治病。四害就是「病」，人生磁場中的病，表現在事業、財運、婚姻、感情、健康、文昌等各種人生百態上。處理四害方法用「拆、補、移、法術、道醫、各種思想」，是一個處理風水的過程。

道家陰盤奇門遁甲只有四條不好的規則，即入墓、擊刑、門迫、空亡（稱「奇門四害」），其中以擊刑和門迫最嚴重。奇門四害是判斷問測者好壞或能量強弱的重要規則。宮位中有奇門四害，稱此宮位不健康、有病，有病的宮位往不好的方向斷；沒有奇門四害不一定好，先以「持平」論。

書頁 179 的「奇門四害表」以黑字標入墓、紅字標擊刑與門迫；
空亡另在第十二節依旬空表判定。整理成文字如下：

自己用神宮位沒有奇門四害，而其他宮位也沒有奇門四害來生或比旺用神宮位的，都稱為「貴人」。剋不一定不好，但不健康的宮位來剋我（日干）則以不好論。

### 二、入墓的化解：用沖
入墓要用沖，就是在對宮擺上相對應的風水物品來沖開入墓。若對宮本身也有四害，效果會比較差，因為對宮本身沒力量沖不開；對宮若有門迫、擊刑、白虎，都要先處理掉，不能讓它沖我，否則佈完局後會形成沖剋，自己已入墓再讓對宮沖剋，反而更慘（變成「沖死」而非「沖開」）。
- 對宮若有庚擊刑和白虎會沖死它，佈局時白虎沖墓會傷人，要先把擊刑（庚）和白虎合掉才可以沖，不能用有害的東西來沖用神宮。
- 特別注意坤宮有值符時，其對宮艮宮一定是白虎；白虎是煞，不要用白虎沖值符，要先把白虎拆掉後再佈局。白虎是有形的煞，玄武是無形的煞。
- 白虎屬陽金（申），化解方式：先用巳把申（庚）合掉（擺蛇），或用天干五合乙庚合（擺葫蘆），不能拆就用合掉。
- 白虎宮位若有庚＋丁：庚在艮宮擊刑又入墓，丁也入墓，如用來沖對宮（坤宮）必出事。若要升官（值符在坤宮入墓），要用對宮沖墓，但因對宮艮宮庚擊刑又入墓、丁也入墓，如沖坤宮會形成沖剋，必傷坤宮，升官不成反而坤宮受傷，得不償失。
- 要去沖別的宮位，本身宮位不能有奇門四害，除了沖不動外還會傷到對宮，形成沖剋，這是自己製造一個不好的東西來沖剋自己，沖則散，也是動盪的意思。
- 宮位基本六個符號有兩個不好的，先把它拆或合掉，買符合另外四個符號象意的物品擺上去來沖對宮。

### 三、門迫的化解：可拆、可合
門迫和擊刑要優先處理。
- 拆：把宮位內門迫物品先拆掉（如驚門在震宮為門迫，把喇叭拆掉即可）。
- 合：因為每個門下都藏有地支，若是門迫時可用合的方法，把門迫合掉。八門藏地支及化解對照（用地支六合＋擺放對應生肖物品＋28星宿符）：
  - 休門（子）：用子丑合，擺牛，配 28 星宿丑宿符。
  - 生門（寅）：用寅亥合，擺豬，配 28 星宿亥宿符。
  - 傷門（卯）：用卯戌合，擺狗，配 28 星宿戌宿符。
  - 杜門（巳）：用巳申合，擺猴，配 28 星宿申宿符。
  - 景門（午）：用午未合，擺羊，配 28 星宿未宿符。
  - 死門（申）：用申巳合，擺蛇，配 28 星宿巳宿符。
  - 驚門（酉）：用酉辰合，擺龍，配 28 星宿辰宿符。
  - 開門（亥）：用亥寅合，擺虎，配 28 星宿寅宿符。

### 四、擊刑的化解：用「合」
擊刑＝地支相刑（刑害、衝突），有處罰之意，能量只剩 50%，投資會虧本。擊刑有固定位置，需要解，解擊刑用「合」。舉例：戊在震宮是擊刑，因甲子戊之子和震宮卯形成「子刑卯」，用地支六合之「子丑合」（擺牛）可解掉戊的擊刑。六組擊刑對應宮位與化解方式：
1. 甲子戊在震宮＝用戊癸合或子丑合，配 28 星宿丑宿符。
2. 甲戌己在坤宮＝用甲己合或卯戌合，配 28 星宿卯宿符。
3. 甲申庚在艮宮＝用乙庚合或巳申合，配 28 星宿巳宿符。
4. 甲午辛在離宮＝用丙辛合或午未合，配 28 星宿未宿符。
5. 甲辰壬在巽宮＝用丁壬合或辰酉合，配 28 星宿酉宿符。
6. 甲寅癸在艮宮＝用戊癸合或寅亥合，配 28 星宿亥宿符。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 奇門四害 | 入墓、擊刑、門迫、空亡，代表宮位不健康的四種狀態 |
| 貴人 | 用神宮位無四害，且其他宮位無四害來生扶或比旺該宮位的狀態 |
| 入墓 | 四害之一，代表有力使不出，需用「沖」化解，但需注意對宮健康狀態 |
| 擊刑 | 四害之一，地支相刑，能量剩 50%，需用「地支六合」化解 |
| 門迫 | 四害之一，可用「拆」或「合」化解，八門各自對應特定地支 |
| 白虎沖墓 | 用白虎沖開入墓宮位時若未先處理白虎本身，反而會傷人，需先合掉白虎 |
| 28星宿符 | 搭配地支六合化解使用的符咒工具，用於加強化解效果 |

## 實務應用場景

- 化解入墓前，務必先確認對宮（要拿來沖的那一宮）本身是否健康，若對宮也有四害需先處理，避免「沖死」而非「沖開」。
- 化解門迫可直接拆除代表物品，或用地支六合對應生肖物品＋28星宿符。
- 化解擊刑固定使用地支六合原則，六組擊刑對應宮位與化解方式已表格化，方便查詢套用。
- 判斷「貴人」宮位：用神宮位無四害，且周邊宮位也無四害來生扶或比旺。

## 我的筆記／延伸思考

- 本節提供的化解表格（八門地支六合對照、六組擊刑化解對照）屬於**高度規則化、可重複操作的固定對照表**，這部分是系統內部一致性最強的內容，很適合直接做成速查卡（見名詞總表），日後排盤時可以直接對照使用，不太有解讀彈性空間，出錯與否較容易核對確認。
- 「白虎沖墓會傷人」「升官不成坤宮反而受傷」這類**具體負面因果宣稱（做錯化解動作會招致實質傷害）**，是目前為止全書中最強烈的因果主張，我認為特別需要謹慎對待：若真的要嘗試這些佈局化解方法，在缺乏可驗證證據支持「做錯會造成傷害」之前，不應該因此感到過度恐懼或迷信化操作流程本身；比較務實的態度是：把這些步驟當作一套需要精確依照說明操作的「儀式流程」，若不確定或無法完整驗證效果，寧可不做，也不必過度擔心「做錯會招致血光之災」等說法。
- 這節內容再次展現這本書的特點：**規則本身結構嚴謹（像一套演算法），但底層的因果假設（物品對應能解決人生問題）本身缺乏可驗證的實證基礎**。可以把這套系統定位成「一種結構化的自我提醒／生活儀式框架」，而非具有實證支持的因果干預工具，這樣使用起來心理負擔會比較健康。
- 上述化解方法是對原書體系的整理，不代表已證實可改善疾病、財務、婚姻或其他現實結果。
