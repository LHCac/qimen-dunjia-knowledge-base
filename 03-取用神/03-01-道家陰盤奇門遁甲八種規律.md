## 原文重點整理

作者提出奇門遁甲模型（九宮八卦盤）之所以能「斷盡天下事」，是因為它遵循以下八種自然界的基本規律：

1. **陰陽規律**：任何事物都可分陰陽兩面（男陽女陰、領導陽員工陰、數字奇偶、電池正負極等）。奇門盤九宮陰陽各半，每宮符號也分陰陽，陰陽是物質的本質。
2. **對立與統一規律**：陰陽既對立又統一，孤陰不生、孤陽不長，任何系統都需要陰陽同時存在才能運作（如天干系統本身即陰陽對立又統一）。
3. **運動規律**：靜止是相對的，運動是絕對的（原子內部電子持續運轉）。奇門盤是「時空模型」，兩小時換一局，一年可演變 4320 局，符號隨時間不斷變動。
4. **普遍聯繫規律**：萬物彼此影響、互相聯繫（如花草生長受土地水光影響）。奇門盤中各符號的旺衰、宮位生剋都是彼此有機聯繫的。
5. **量變到質變規律**：事物的量累積到臨界點會產生質變（如冬至夜最長後晝漸長，夏至產生轉折）。奇門盤中符號好壞的變化也反映這種質變過程。
6. **物極必反規律**：事物發展到極致會反轉（太極圖黑白互變）。如天干十二長生走到「帝旺」後即轉衰、病、死、墓、絕。
7. **波浪式前進規律**：變化非直線而是曲線（如股市、人生、植物生長）。天干旺衰排列表、十二長生狀態即體現此規律。
8. **週期規律**：天體運行具有週期性（月繞地球、地球自轉公轉、四季循環）。奇門盤兩小時一換符號，同樣是周而復始、有序排列運動的。

作者並舉環保為例說明「物極必反」：過度砍伐森林導致水患、過度捕獵導致生物鏈失衡（鼠患），呼應這些規律不只用於占卜，也適用於自然與社會。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 陰陽規律 | 萬物皆可分為對立的陰陽兩面，是奇門盤符號分類的基礎 |
| 對立與統一規律 | 陰陽既互相對立、又必須共存統一才能構成完整系統 |
| 運動規律 | 表面靜止的事物，內部本質上仍在持續運動變化 |
| 普遍聯繫規律 | 萬事萬物彼此影響，沒有孤立存在的事物 |
| 量變到質變規律 | 量的累積達到臨界點會引發性質上的轉變 |
| 物極必反規律 | 事物發展到極致會朝相反方向轉化 |
| 波浪式前進規律 | 事物發展呈曲線起伏，而非直線前進 |
| 週期規律 | 天體與自然現象具有循環往復的規律性 |

## 實務應用場景

- 作為理解後續所有「符號」「宮位變化」「長生十二運」等操作規則的哲學前提。
- 解盤時判斷事情「正在發生什麼階段」（量變/質變、上升/物極必反）可作為敘事框架。

## 我的筆記／延伸思考

- 這八條規律基本上是中國傳統「一分為二、對立統一」哲學（也很接近唯物辯證法的表述方式），**屬於世界觀層級的敘述，不是可驗證的具體命題**。像「物極必反」「量變質變」這類說法涵蓋範圍太廣，幾乎可以解釋任何後續發生的事（可證偽性低），閱讀時應視為「敘事框架 / 隱喻工具」，而非科學定律。
- 真正可以拿實際案例驗證的，是後面章節中「特定符號組合 → 特定具體事件」的斷語（例如某天干臨某宮代表破財），這節純屬鋪陳世界觀，暫不涉及可驗證的因果宣稱。
- 值得注意的是，本節內容其實跟《易經》原有的陰陽辯證思想，與 20 世紀後半期引入華文世界的辯證唯物論語彙（對立統一、量變質變、否定之否定）有高度重疊，這可能反映此書成書年代或作者知識背景，可作為考證此書思想脈絡的線索，而非命理本身的依據。
