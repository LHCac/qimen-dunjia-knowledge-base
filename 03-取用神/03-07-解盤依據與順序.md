## 原文重點整理

### 一、精氣神形與改運原理
奇門盤內每個符號都有精、氣、神、形，有其形必有相對應之人、事、時、地、物。作者主張：只要符號「有形」，就可以在問測者家中周遭找到相對應的實物，找到癥結點加以調理後就可以改運（若癥結點不在家裡，環境就會對應到人的身上）。氣是作用、神是規律、固體結晶成形、形往上升華變氣。道家陰盤奇門遁甲大約 50% 都用「形」，因此作者稱奇門遁甲與「形家」（風水中重視具體形勢的一派）有很多類似之處。

### 二、單宮斷與全盤斷
道家陰盤奇門遁甲分為單宮斷和全盤斷：
- 需先把問題講出來，全盤斷就是把整個盤當作命盤來看：先看日干、時干，問感情再看合干，問健康需加看天芮星等相關訊息。
- 解盤要先看「大象」（先看全局），再看與用神有關的符號。
- 解盤要先取象直讀，加看四害，再尋象應數。書中比喻：符號是老鼠，四害就是貓，若無四害表示貓還在睡覺（尚未發作）。
- 天機藏在動處（變處），問測者的問題就在「四綱」裡頭找。解盤要先知道用神，才不會偏離主題；打開盤先看日干宮，第二看時干宮，要先看天地盤再看符號。不看生剋就能知道問題所在，生剋是後面的事。

### 三、用神優先順序與四個判斷依據
1. **用神宮位（第一位）**：以用神宮立太極，只問當事人本身問題時，日干宮為第一用神；日干健康無病再看時干（事）。若問客戶，用神宮就是客戶，必須詢問客戶（尋象應數）才能找到癥結點。要先知道客戶要的是什麼（如價位、品牌、包裝、口味），再往這方向思考，不要亂翻亂轉，只要在用神宮找就可斷出七、八成準確度。
2. **時干宮（第二位）**：稱「先鋒門」，如同先發部隊，代表露出跡象。時干為近期、未來或即將發生的事，也表示未來可能的行動方向。時干狹義為事，廣義為人事時地物；若問合夥，時干為合夥人，若時干為玄武表示合夥人有詐。
3. **空亡宮（第三位）**：空亡代表變、代表轉變。
4. **馬星（第四位）**：代表打算會有什麼樣的轉變或異動，這些都是「天機藏在動處」的呈現。

這四個宮位需要交集聯想，一定會有訊息顯現出問測者最近會發生或想要發生的事情。

### 四、其他重點
- 日干宮是一個人的運勢：問考運、財運、官運、身體狀態、疾病，所有問運勢的問題都要先看日干宮。疾病的日干宮代表遺傳體質，所有關於疾病的用神都在日干宮，包含隱干。
- 主次不分：日干宮沒有看清楚就跳到其他宮位看，會把不重要的當最重要看，其實答案往往已在日干宮出現。
- 要先看地盤干、再看天盤干，再把神、星、門、隱干看清楚後，才做完整綜合判斷。
- 尋象應數：尋象＝看盤的符號，應數＝對方回應的資訊，在一問一答狀態下幫他解惑；若沒有這個雙向核對過程，「都是在亂猜」。到最後熟練時「盤占 30% 的資訊，現象占 70% 的資訊」，甚至不用開盤，問題已有蛛絲馬跡。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 精氣神形 | 奇門盤符號的四種層次屬性，「形」是實體對應物，可用於改運調理 |
| 形家 | 風水學派中重視實際地形地物的一支，本書認為奇門遁甲與其類似 |
| 單宮斷 | 只針對單一宮位進行的解讀 |
| 全盤斷 | 把整個奇門盤當作命盤來綜合解讀 |
| 尋象應數 | 解盤者觀察符號（尋象）並與問測者互動核對回應（應數）的雙向過程 |
| 用神宮位 | 第一優先查看的宮位，代表問測者本身或客戶的核心處境 |
| 先鋒門 | 時干宮的別稱，代表即將發生、未來的行動方向 |
| 主次不分 | 未按優先順序解盤、把次要宮位當最重要看的錯誤 |
| 交集聯想 | 將日干宮、時干宮、空亡宮、馬星四個宮位訊息交叉比對聯想 |

## 實務應用場景

- 標準解盤流程：先定用神，以日干宮為主；在用神宮內先看地盤干、再看天盤干，綜合神、星、門、隱干；之後再參時干宮、空亡與馬星，做交集聯想。
- 面對問測者時務必進行「尋象應數」（雙向詢問核對），而非單方面套用符號意義自行腦補。

## 我的筆記／延伸思考

- **「尋象應數」是本節中最重要、也最誠實的一句話**：作者明確承認，如果沒有跟問測者互動核對，「都是在亂猜」。這其實間接承認了單靠符號系統本身無法保證準確，準確度很大程度上依賴解盤者與問測者之間的對話互動——這也呼應冷讀術（cold reading）常見的運作機制：透過提問與觀察反應逐步修正解讀方向，讓最終答案顯得「精準」。這點值得特別標註，是評估這套系統有效性時最關鍵的方法論警訊。
- 「盤占 30%、現象占 70%」這句話進一步印證上述觀察：作者自己也承認盤面本身資訊量有限，大部分判斷準確度其實來自解盤者對「現象」（即問測者透露的線索與反應）的敏銳觀察與詢問技巧，而非盤面符號本身的預測力。
- 「形」的改運邏輯（找到對應實物調理即可改運）是一個**強因果宣稱**（調整環境物品→改變運勢），這部分理論上是可以設計對照實驗來驗證的（例如追蹤多個案例：佈局前後的具體可測量結果變化），但目前書中沒有提供任何對照組或追蹤數據，屬於待驗證假說，之後若要記錄案例，建議明確記錄「佈局前狀態、佈局內容、佈局後具體結果、時間間隔」，方便日後統計檢視。
