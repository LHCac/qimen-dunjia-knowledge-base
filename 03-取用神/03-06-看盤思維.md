## 原文重點整理

### 一、重要性排序
「天時不如地利，地利不如人和，人和不如神助」——「神助」的規律大於一切。每一宮中，八神起了領袖作用，事物都具有八神的性質。時干是先鋒為主幹，轉宮內藏玄機。

### 二、斷事三步驟
1. **第一步**：先看日干宮地盤天干（問測者會遇到的狀況），再與天地盤合看。
2. **第二步**：看時干宮狀態＝問測者所問的（人、事、時、地、物及一切想要問的事情）。
3. **第三步**：看第三用神——特殊相關的問題。

### 三、天盤與地盤的重要性差異
- 天盤是已經浮出水面的事情，地盤是將要或正在發生的事，代表未來將要發生、繼續發生的事情。
- 「陰的東西比陽的厲害」——**地盤比天盤重要**，沒有浮出水面的東西比浮出水面的力量大。天盤代表一個人的性格，地盤代表他的內心世界。

### 四、天干兩兩組合象意舉例（以乙為例，代表「她」）
- 乙+庚：女測，長得苗條，曾有男朋友且同過床，同床對象是公檢法官或黑社會人士
- 乙+乙：帶耳環、項鍊
- 乙+丁：男測婚姻，老婆會叫床、伶牙俐齒、說話帶刺
- 乙+丙：老婆不顧家，有魄力，辦事出亂子
- 乙+戊：老婆會持家，管錢有方，憨厚老實
- 乙+己：主意多，會策劃
- 乙+辛：老婆一說就錯，口無遮攔
- 乙+壬：閒不住，任勞任怨，懷孕了
- 乙+癸：好色、性慾強

### 五、應期
應期＝非沖即填。沖的力量大，填實力量比較小。用神逢空亡時，應期時間要延長一些，效力小一點，轉一宮時間慢一步。

### 六、空亡
空亡是「玄機點」，相當於冬至點，是陰陽轉換的下一個玄機點，相當於人的會陰穴（生殖系統），是從有到無、從無到有的轉換點。若要發展經濟可找空亡點（有空隙可鑽），想生孩子也找空亡點。

## 關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 神助規律 | 作者主張「神助」在天時地利人和神助四要素中影響力最大 |
| 第一用神 | 日干宮，代表問測者現在的處境與遭遇 |
| 第二用神 | 時干宮，代表問測者所問之事，也稱先鋒／先機 |
| 第三用神 | 特殊相關問題的補充用神宮位 |
| 應期 | 問測事件實際發生／應驗的時間點 |
| 非沖即填 | 判斷應期的原則：對宮沖動或填實原宮位地支時容易應驗 |
| 空亡玄機點 | 空亡代表陰陽轉換的關鍵節點，象徵狀態轉移的可能性 |

## 實務應用場景

- 斷盤固定流程：先看日干宮（第一步）→ 再看時干宮（第二步）→ 再看第三用神（第三步），避免「主次不分」。
- 判斷特定人物特徵或親密關係細節時，可用天干兩兩組合的象意表對照（本節列出以乙為例的九種組合）。
- 判斷「何時會發生」問題時，運用應期「非沖即填」原則。
- 針對創業／生育問題，作者會把空亡宮位視為「玄機點」；此為書中術數用法，不是財務或醫療建議。

## 我的筆記／延伸思考

- 「地盤比天盤重要」「陰的東西比陽的厲害」這類規則屬於系統內部的**優先權規則**，是操作上的約定（類似程式語言的運算子優先順序），本身無所謂真假，重點是能否始終如一地套用。
- **天干組合象意表（如乙+庚＝苗條、曾與公檢法人士同床）是本節中最值得標記為「高度具體、極易被證偽或證實」的斷語類型**：因為它給出的是非常具體、可核對的個人特徵與經歷細節。這類細節化斷語如果能大量蒐集真實案例（例如記錄多次占測的天干組合與後來核實的當事人真實狀況），是最適合做統計式驗證的素材——但也要注意這類斷語本身帶有強烈刻板印象色彩（如「乙+庚」與特定職業掛鉤），使用與記錄時宜保持中立客觀，不宜先入為主。
- 「空亡代表生育／創業最佳時機」這類具體時機建議，如果真的要應用在人生決策上（例如懷孕計畫），建議務實上仍以醫學、財務等實證資訊為主，命理判斷可以參考但不宜作為單一決策依據——這正好呼應我自己重視科學務實的立場。
- 應期「非沖即填」的規則本身結構清晰，是這整本書中少數有明確、可操作、可事後核對「準或不準」的具體規則之一，值得優先納入之後的案例驗證清單。
