## 一、原文重點整理

### 1. 考試/面試三大判斷方向
1. **日干**為問測者本人,從日干落宮可看出考生目前狀態、特長、優勢。
2. **時干**為問測者所問之事,代表事情發展趨勢與未來結果。
3. **第三用神**——判斷能否考上的關鍵,依科目選定對應天干符號的落宮。

### 2. 十天干對應科系(選填志願/判斷孩子適合科系用)
| 天干 | 對應科系/領域 | 說明 |
|---|---|---|
| 甲(值符)、丙 | 政治 | 甲為領導,丙為權柄 |
| 乙 | 藝術、美術、才藝 | — |
| 丁 | 語文 | 丁為叮叮噹噹,代表說話 |
| 戊 | 經濟、會計、財稅、金融、地理 | 戊是本金、錢、利潤 |
| 己 | 歷史 | 己是墳墓(過去的東西) |
| 庚 | 物理、實驗 | — |
| 辛 | 化學 | 辛為創新、改革、變化 |
| 壬 | 數學 | 壬主智,代表邏輯推理能力 |
| 癸 | 生物 | 癸代表陰暗、地下的東西、寄生蟲、細菌 |
| 天英星 | 英文 | — |
| 天輔星 | 學校或老師 | 問跟老師有關看天輔星,問同學相處用月干 |
| 馬星 | 體育 | 天沖星、傷門都在震宮屬動,也代表體育 |

### 3. 值符角色
值符為主考官(大主考官在年干,代表考試主委)或面試官。

### 4. 判斷科系適合度的方法
- 開盤後找第三用神(例如看數學就看「壬」的落宮,看物理就看「庚」的落宮)。
- 看該用神落宮是否健康(有無四害),再與問測者(日干)比較生剋關係。
- 第三用神落宮有奇門四害 → 不適合就讀該科系;若與日干相生或比旺 → 適合就讀。

### 5. 判斷考試運
- 看日干落宮及時干落宮的生剋關係。若要考頂尖學校(如台大),不能只有一個吉利符號,「考試符號越多越好」。
- 孩子學習狀況最好宮位內有「丁」,因為丁主考試、科甲、文昌。
- 乙丙丁配合最佳,日干落宮組合以「丙+丁」「乙+丁」「戊+丁」最好。

### 6. 具體吉凶判斷
- 若日干有奇門四害的**入墓、門迫、擊刑、死門**,又有玄武(頭腦不清)→ 一定考不好。
- 若日干落宮臨**值符**(高中)、臨**九天**(分數高)、臨**太陰**(心思細膩、頭腦聰明)→ 考得好。
- 若臨**九地**(分數低)→ 落榜。

## 二、關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 第三用神 | 除了日干(自己)、時干(所問之事)之外,依考試科目另外選定的第三個判斷符號,是本節特有的用神選取邏輯 |
| 科甲 | 傳統科舉考中之意,此處引申為考試順利、榜上有名 |

## 三、實務應用場景
- 研究作者把天干、九星與科系／考試表現連結的方法。
- 真實選系與考試準備應以興趣、成績、課程內容、職涯資訊與師長建議為主，不能用盤面替代學習或升學決策。

## 五、驗證備註

**書上定義的規則：**
- 十天干對應科系表(甲丙=政治、乙=藝術、丁=語文...)是全書中最像「聯想式分類系統」的一節,例如「丁=叮叮噹噹=語文」「己=墳墓=歷史」這類推理明顯是**望文生義的聯想**,而非有邏輯必然性的對應,屬於系統內部的約定俗成,沒有客觀對錯可言。

**可驗證的因果宣稱,而且是這本書中少見「可以拿真實客觀分數驗證」的題材：**
- 「日干符號組合越多吉利符號(丙+丁、乙+丁、戊+丁)→ 考試分數越高」是可以量化驗證的假說,因為考試分數是客觀、公開、可比對的數據。
- 更重要的是「第三用神落宮健康度 → 該科目是否適合就讀/該科目考得好不好」這條規則有明確的操作型定義,建議未來系統性驗證時可以:(1) 收集多個考生的出生/起盤時間與各科落宮狀況、(2) 對照該科目實際成績、(3) 計算相關性。如果第三用神真的能預測特定科目表現,應該會看到統計上顯著的相關,而不只是少數個案吻合。
- 要注意混淆變數:考生本身的讀書時間、資質、家庭資源等因素對成績的影響遠大於玄學變數,若做驗證應盡量控制或至少意識到這些干擾因素的存在,避免把「本來就該考好的學生剛好符合吉利符號」誤判為玄學系統的預測力。
