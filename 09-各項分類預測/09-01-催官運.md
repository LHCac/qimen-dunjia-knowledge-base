## 一、原文重點整理

### 1. 判斷升官運的基本邏輯
- 先看**自己用神宮位**好不好。若宮位臨「值符、太陰、九天、馬星、丙」其中之一,代表有往上發展的機會。
- 若沒有這些符號,且日、時兩宮又逢奇門四害(門迫、擊刑、空亡、入墓等)相剋,則視為「動不了」,難以升官。

### 2. 官星理論
- 官星分兩顆:「正官」與「七殺」。
- 書中特別強調:要調官運,關鍵是調「七殺宮位」來生日干宮(而非正官),因為七殺同時也代表「墓地」的概念。
- 判斷方式:
  - 七殺生您、比和您 → 順利。
  - 七殺剋您(約束您)、洩您、耗您 → 不可能升遷。
  - 您剋七殺 → 升官也慢。

### 3. 調理方法
- 用「移星換斗」的技法,把七殺宮位調整到「來生」或「比旺」日干宮的位置。
- 重要原則:調整後的兩個宮位(日干宮、七殺宮)都不能帶有奇門四害,否則調理無效。

### 4. 跟升遷相關的四個符號(升遷、考運「重八神」的概念)
| 符號 | 代表意義 | 升遷條件 |
|---|---|---|
| 值符 | 頭兒、主管、科甲 | 日干宮和值符宮有相連符號、先後天關係、相生比和關係,時間到就升官 |
| 九天 | 發展抱負的機會 | 自己落宮沒有奇門四害時效果最好;若逢四害則稱「高射炮」——白日夢、眼高手低、心高氣傲 |
| 太陰星 | 護佑、保護、提升(印我、助我) | 落宮中有太陰星,時間到有升遷機會 |
| 馬星 | 動、異動 | 日干宮或時干宮臨馬星且無四害,時間走到職務就有異動可能 |

### 5. 升遷/調動/官運的宮位對應
- 日干 = 自己
- 時干 = 部屬、員工
- 月干 = 同事、競爭對手
- 年干 = 上級領導、老闆、總裁
- 值符 = 頂頭上司、主管

### 6. 判斷求測人自身條件
要綜合判斷八神、天干、九星、八門、隱干符號的組合象意:
- 八神 → 主要性格、特點
- 天干 → 從事的事業性質
- 九星 → 事業性質的概括
- 八門 → 事業性質的特點
- 隱干 → 事情能否達成的近因與遠因

### 7. 十八種升遷/降調常見斷法
| # | 狀況 | 斷語 |
|---|---|---|
| 1 | 時干剋日干 | 必降調 |
| 2 | 伏吟平穩不動 | 不易有機會升官 |
| 3 | 反吟 | 主調任,但不一定升官 |
| 4 | 空亡 | 必革職 |
| 5 | 入墓 | 主丟工作,易被炒魷魚 |
| 6 | 年干剋日干 | 領導不喜歡您 |

| 9 | 時干來剋 | 手下人員不服氣 |
| 10 | 日干臨門迫、擊刑 | 能力發揮不出來,擰扭等 |
| 11 | 日干臨值符 | 上司提拔 |
| 12 | 年干生日干 | 領導喜愛提拔 |

## 二、關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 用神 | 代表求測事項本身的宮位符號,是判斷吉凶的核心參照點 |
| 七殺 | 八字/奇門中官星的一種,此書特別將其與「墓地」概念連結,強調要調七殺宮位生日干才能催官 |
| 移星換斗 | 書中反覆使用的調理技法,將盤面某宮位符號「順轉」若干宮位,模擬改變能量分布以達成調運效果 |
| 奇門四害 | 門迫、擊刑、空亡、入墓的統稱,代表能量受阻或耗損 |
| 伏吟 | 盤局中某宮天地盤符號相同、不動的狀態,象徵停滯 |
| 反吟 | 盤局中對宮符號相沖的狀態,象徵變動、反覆 |

## 三、實務應用場景
- 想知道自己今年是否有升遷機會,可依此節方法找日干宮與七殺宮的關係做初步判斷。
- 若已知不利,可依「移星換斗」原則設計佈局(需注意兩宮都不能有四害)。

## 五、驗證備註

**屬於「書上定義的規則」(封閉系統內的推理,不涉及外部驗證)：**
- 值符=主管、太陰=印我助我、七殺=墓地 這類「符號↔語意」的對應關係,本質上是這套術數系統內部的定義,類似字典,沒有「對不對」的問題,只有「用得熟不熟」的問題。

**屬於「可以拿案例驗證真偽的操作性宣稱」(以後可以系統性追蹤)：**
- 「七殺宮位生日干宮 → 會升官」這類具體的**條件→結果**斷語,理論上是可以做**追蹤驗證**的:例如記錄自己或朋友每次起盤時七殺宮與日干宮的關係,和半年後是否真的升遷做對照,累積十幾二十個樣本後看命中率。
- 十八種斷法中,「必降調」「必革職」這種措辭非常武斷(用「必」字),這種強斷語反而最適合被證偽——如果日後案例庫中出現「時干剋日干但沒有降調」的反例,就要記下來檢驗這條規則的可靠度。
- 這節沒有講「基期比較」——也就是沒說「不用奇門遁甲,單純看一般升遷統計機率是多少」,若要嚴謹驗證因果關係,理論上還需要一個對照組(沒算過盤的人升遷率 vs 算過盤且符合條件的人升遷率),但這在民俗實務上很難做到,只能做「事後驗證是否吻合」的弱驗證。
