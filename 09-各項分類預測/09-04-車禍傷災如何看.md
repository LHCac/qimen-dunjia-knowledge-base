## 一、原文重點整理

### 1. 基本邏輯
看車禍要看「四綱」(年、月、日、時所落的宮位),哪個宮位有奇門四害,車子相對應的部位就容易出問題。

### 2. 車體八卦部位對應表
| 方位 | 車體部位 |
|---|---|
| 左前 | 車頭左側 |
| 車頭(正前) | 車頭正面 |
| 右前 | 車頭右側 |
| 左側 | 左側車身 |
| 右側 | 右側車身 |
| 左後 | 車尾左側 |
| 正後 | 車尾正面 |
| 右後 | 車尾右側 |

### 3. 判斷某人是否會出車禍
- 若四綱落宮有奇門四害,容易出車禍。書中強調「要描寫汽車來撞您或是您去撞人是很講究的」——需要把「造成傷害的物體」形象化模擬出來,再開盤看車子哪個部位受傷。

### 4. 詢問車禍發生方位(以八卦宮位對應被撞方向)
| 宮位 | 被撞方向 |
|---|---|
| 巽宮 | 左前方被撞 |
| 離宮 | 正前方被撞 |
| 坤宮 | 右前方被撞 |
| 震、兌宮 | 車腰被撞 |
| 艮宮 | 左後方被撞 |
| 坎宮 | 正後方被撞 |
| 乾宮 | 右後方被撞 |

### 5. 車子毛病的判斷
哪個宮位出現「傷門、天芮星」或四害符號,車子對應部位就出問題,應期(車禍發生時間)則對照該宮位所代表的年月日時。

### 6. 化解方式
書中提出可以用「拆、補、移」三種手法幫當事人減災(拆除形煞、補強不足、移動調整),但此節未展開細節,詳見後續章節。

## 二、關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 四綱 | 本節用來指年、月、日、時落宮；與本書第 1 章把「四綱」列為年干、時干、月干及夫妻／情人五合關係的定義不一致，使用時須按章節脈絡辨別 |
| 應期 | 事件實際發生的時間點,依宮位對應的年月日時推算 |
| 拆補移 | 化解不利格局的三種基本手法:拆除、補強、移動 |
| 傷門 | 八門之一,象徵受傷、損害 |

## 三、實務應用場景
- 可作為研究本書車禍斷法的索引；實際行車安全應以車況檢查、守法駕駛、路況與疲勞管理為準，不能用盤面取代安全措施。

## 五、驗證備註

**這節是全書中最容易「事後可驗證」的一類斷法：**
- 車禍發生的方位、部位、時間都是具體、客觀、可查證的事實(不像「財運」「小人」那樣主觀模糊)。理論上這是這套系統中**最適合做嚴謹驗證**的題材之一——如果之後你真的要系統性測試這套術數的準確度,車禍應期預測會是一個好的切入點,因為驗證標準明確(有沒有撞?撞在哪?什麼時候?),不太會有各說各話的模糊空間。
- 建議做法:如果未來要驗證,可以找已發生車禍的案例,回推事發時的四柱落宮與奇門四害位置,反著驗證「四害宮位」是否真的對應到「實際受損部位」與「實際方位」。但要小心**選擇性回溯**的問題——因為八卦只有八個方位,隨機猜中「哪一側」被撞的機率本來就有 1/8 起跳,须比較這套方法的命中率是否顯著高於隨機猜測。
- 「事先預測某次特定行程是否會出車禍」比「事後歸因車禍發生在哪」難得多,如果要驗證這套系統的預測力(而非僅僅是事後解釋力),應以「事前預測、事後對照」為主,而非只驗證事後的符合度。
