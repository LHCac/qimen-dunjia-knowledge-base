## 一、原文重點整理

### 1. 判斷是否適合炒股
- 看時干、年干是否生日干或年命。
- 看生門是否生日干或年命。
- 看戊(代表資本、資金)是否臨玄武。
- 看終身局是否命中有財、近期是否有財運。

### 2. 選股基本邏輯(先起局預測)
1. 時干、年干是否生日干或生年命。
2. 生門是否生日干或年命。
3. 甲子戊是否乘玄武。
4. 選股票要先起局預測,看自選股票宮位與日干宮的關係,年命也可做參考。

**經驗法則**:日干好、年命不好 → 適合短期經營;日干不好、年命好 → 可長線操作;日干和年命都好 → 適合炒股。

### 3. 選擇最佳股票及時間的宮位邏輯
- 日干 = 買股者;時干 = 大盤;戊 = 資本;生門 = 利潤。
- 值符、景門 = 行情;值使門 = 漲跌的幅度、中間過程、炒作方向及性質(股票種類)。
- 能否超過前期高點:先確定「前期」是哪個時間點,通常時干宮地盤、值符地盤天干也代表前期。值使門代表方向與漲跌幅度。
- 九天臨景門旺 → 政府資訊;值符臨景門 → 銀行方面資訊;年干 → 政府與股市管理機構。

### 4. 漲跌與盤面性質的判斷
| 符號 | 象徵意涵 |
|---|---|
| 日干臨騰蛇 | 變化、虛假;顯示資訊不可靠 |
| 日干臨白虎 | 殺傷力強;值使門與時干臨白虎,大盤要跌 |
| 日干臨玄武 | 投機、炒短線 |
| 日干臨九地 | 屯積、慢、長線 |
| 日干臨九天 | 上升、沖高,但下落很快,防回落,隨時準備出貨 |

## 二、關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 值使門 | 八門中對應「值符」的門,此節用於代表漲跌幅度與操作方向 |
| 生門 | 代表利潤、獲利的核心符號 |
| 終身局 | 依出生時間起的長期命局盤,用以判斷財運的整體格局(而非單次事件盤) |

## 五、驗證備註

**這是全書中我認為最需要小心的一節,原因如下：**

1. **股市是全世界研究最透徹的「難以預測系統」之一**。有效市場假說(EMH)雖然本身也有爭議,但長期大量學術與實務證據都顯示:短期價格走勢極難被系統性預測,能長期打敗大盤的方法極少,而且多半基於資訊優勢或統計套利,不是符號玄學。任何宣稱能穩定預測漲跌的方法,都應該用「極高的懷疑標準」來檢視。

2. **可驗證,但風險是驗證方式容易失真**:這節的斷語(例如「日干臨白虎→大盤要跌」)理論上完全可驗證——只要記錄每次起盤的判斷方向,和實際大盤漲跌對照即可。但要注意:
   - 如果只記錄「說中的案例」而不記錄「說錯的案例」,會嚴重高估準確率(倖存者偏差/確認偏誤)。
   - 「上漲」「下跌」是二選一的判斷,隨機用擲硬幣的方式都有約 50% 的命中率,若要說這套方法「有效」,命中率必須顯著高於 50% 且要有夠大的樣本數(至少幾十次以上,且最好是連續事前預測、事後才對答案,而不是先看盤面再回推解釋)。

3. **本書第十章「案例四」(美國大選+台股跌點預測)聲稱精準預測台股跌 274 點,這類「單一神準案例」在統計上意義有限**——一次命中不能證明系統有效,可能是運氣,也可能是「多重嘗試後只公布命中的那次」(例如同時猜測多種點數,只展示猜對的)。如果你之後真心想驗證,建議自己每次「事前」寫下明確、可證偽的預測(方向+大概區間),再看後續對照,累積至少 20-30 次獨立樣本,才有基本的統計意義。

4. **務實建議**:即使這套系統的符號邏輯自洽、有趣,作為興趣研究和自我覺察工具沒有問題,但**不建議把實際投資決策的權重放在這類預測上**,尤其是資金部位配置這種有真實財務後果的決定,更應該以基本面、技術面、風險管理等有實證基礎的方法為主。
