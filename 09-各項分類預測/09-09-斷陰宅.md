## 一、原文重點整理

### 1. 陰宅地形符號對應(斷陰宅如)
| 符號組合 | 對應地形 |
|---|---|
| 戊+己 | 祖墳東邊有水坑或下陷,長滿雜草 |
| 戊+辛 | 祖墳東邊有他人的墳、有小路、有小石堆 |
| 戊+庚 | 祖墳東邊有馬路、有別人墓碑沖著祖墳 |
| 戊+丁 | 東邊有叉路、丁字路 |

- 丙丁在墳地代表高嶺;庚辛為道路與圍牆;壬癸為長河及溝澗(低窪);戊己為墳看旺處;甲乙為木看見樹。
- 書中強調斷得準是一種「規律」(神助),意即這套符號對應是他實務歸納出的固定規則。

### 2. 調陰宅原則
- 調陰宅就是把「主要的人」調好,概念類似「一人得道、雞犬升天」——即找到影響力最大的往生者,針對其墳位做調理。
- 現場起局能了解該墳對誰好、對誰壞,並用拆補移的大法進行調理。

### 3. 陰宅與後代的連動關係(核心觀念)
- 親人葬在好地理,親人的靈骨會與大地環境產生「共振」,進而與後代子孫產生共振、對其產生影響。
- 判斷墳內死者在家排行:起局後看日干宮落在哪一宮,對照下表:

| 宮位 | 對應排行 |
|---|---|
| 巽宮 | 1、4、7 |
| 離宮 | 3、6、9 |
| 坤宮 | 2、5、8 |
| 震宮 | 3、6、9 |
| 兌宮 | 1、4、7 |
| 艮宮 | 2、5、8 |
| 坎宮 | 1、4、7 |
| 乾宮 | 3、6、9 |

- 判斷死因看日干宮位內的符號訊息。
- 影響力排序(依血緣親疏與時間遠近):最近過世者影響最大;直系血親中,媽媽的墳影響力大於爸爸,爸爸大於奶奶,奶奶大於爺爺,依序遞減。父母合葬看墓碑及墓的全部。親生父母的墳影響出嫁女兒也一樣有效(血緣關係),先生父母的墳對妻子也有一定作用。

### 4. 案例:高雄美濃第五公墓現場開盤解說(2017/11/1)
背景:友人介紹到高雄勘墳,該墳坐子向午,後代子孫最近發生多起意外(大姊腦瘤、二子喉嚨意外受傷、三子眼睛不佳)。

**解析重點**:
1. 該盤為反吟盤,子孫反覆發生意外事件被視為「必然」結果。
2. 墳前、後都凹陷二米以上,旁邊兩側都有他墳反弓及尖物形煞(離庚、坎庚、巽丙、坤戊丁)。
3. 前面三劫位(巳4月、午5月、未6月、申7月)形煞迭見,中間形成「窄管風煞」,對二子影響最大,對應到二子在農曆五月發生意外(頸部、喉嚨)。
4. 坤宮(地刑位)多墳尖物從高處直射,對應三子眼睛受影響。
5. 巽宮天劫位(左前一墳高出很多形成反弓煞),左前方在女兒部分對應大姊(腦部病情)。

**作者提出的處理方案**:在正前方種植較高銀柏，並移除部分水泥、改種地毯草。任何墓地改動都必須先確認土地、墓園、家屬與主管機關的權限，並由合格人員評估結構、排水與施工安全。

## 二、關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 地刑位 | 此節指坤宮方位,象徵形煞直射、對特定身體部位造成影響的位置 |
| 天劫位 | 此節指巽宮方位,象徵高聳反弓形煞的位置 |
| 反吟盤 | 對宮沖剋的盤局狀態,此節解讀為「事件反覆發生」 |
| 共振 | 書中用以解釋陰宅與後代連動關係的核心概念,借用物理學詞彙但未提出可驗證的機制說明 |

## 三、實務應用場景
- 掃墓或選墓地時,依戊己丙丁庚辛壬癸符號對應初步檢視周遭地形是否有形煞。
- 研究作者如何把墓地環境與家族事件連結；疾病、事故或家族衝突仍應分別尋求醫療、警方、工程或法律等可驗證的專業協助。

## 五、驗證備註

**這節是全書中最需要科學檢視的章節之一，原因如下：**

1. **「共振」一詞的借用問題**:書中用「共振」解釋祖先靈骨與後代的連動關係,但「共振」在物理學中是有嚴格數學定義的現象(頻率匹配、能量耦合),此處只是借用詞彙的比喻性說法,並沒有提出任何可測量、可重複驗證的物理機制。這是玄學文獻中常見的「借用科學術語增加說服力」現象,值得特別標註提醒自己不要被術語的「科學感」誤導成真的有科學基礎。

2. **可驗證但因果方向難以釐清的部分**:
   - 案例中「墳墓周圍形煞方位 → 對應到特定子女受傷部位」的斷語表面上具體可查(左前=大姊腦部、坤宮=三子眼睛),但這類**先有結果(家族已發生意外)再回頭找墳墓形煞來對應**的操作方式,是典型的**德州神槍手謬誤**(先射箭再畫靶):形煞方位有 8 個宮位,家人有多位、身體部位有很多種,只要找得夠仔細,幾乎一定能找到某種「說得通」的對應關係。
   - 若要真正驗證這套系統的預測力,應該反過來做:**先看墳墓格局起局,在任何家族成員發生意外之前,先預測「哪個方位形煞會對應哪位家人的哪個部位」,再等待驗證是否成真**。書中所有陰宅案例都是「事後解釋」型,沒有一個是「事前預測後應驗」的案例,這是判斷這套理論可信度時最關鍵的方法論缺口。

3. **務實建議**:掃墓或選墓地時,環境是否排水良好、周遭是否有實際安全疑慮(如地質鬆動、道路沖煞造成視線死角等)本身就有實用價值,可以獨立於玄學系統之外用常識判斷;但「陰宅影響後代健康/意外」這類強因果宣稱,建議保持高度存疑態度,不要因為單一或少數幾個「說中」的案例就全盤採信。
