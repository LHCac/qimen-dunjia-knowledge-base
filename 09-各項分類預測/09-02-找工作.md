## 一、原文重點整理

### 1. 找工作預測涵蓋範圍
畢業分配、求職就業、競爭求職、晉升職位、官職升降、工作調動等,都屬於此類。

### 2. 宮位角色分配
- 開門 → 代表文職工作及單位
- 杜門 → 代表武職工作及單位(技術性、專門性質)
- 年干 → 上級領導
- 值符 → 頂頭上司
- 月干 → 同事
- 日干 → 求測之人(自己)
- 時干 → 下級或單位員工群眾

### 3. 求職成敗判斷
- 日干或年命落宮旺相、無奇門四害 → 自身條件好,得天時地利。
- 若再得太陰、值符、九天來生日干 → 求職得官順利。
- 值符來剋日干宮 → 文官職降調。
- 杜門剋用神 → 武官職降職。
- 反吟主調任;空亡必革職;入墓不但降罰,還會招來罪戾。
- 太歲來剋 → 上級領導不喜;值符來剋 → 頂頭上司不愛;月干來剋 → 同事競爭;時干來剋 → 下屬告狀。

### 4. 日干所臨九星對應人品(附帶知識點,常用於面試/求職對象個性判斷)
| 九星 | 人品特質 |
|---|---|
| 天輔星 | 文雅 |
| 天任星 | 慈祥 |
| 天心星 | 正直 |
| 天沖星 | 鋒厲 |
| 天英星 | 剛烈 |
| 天芮星 | 貪瀆 |
| 天柱星 | 奸詐 |
| 天蓬星 | 大惡 |

## 二、關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 開門 | 八門之一,象徵開創、公開、文職性質的機會 |
| 杜門 | 八門之一,象徵閉塞、隱藏、專門技術性質 |
| 太歲 | 年份對應的地支能量,代表大環境或最高層級的影響力 |

## 三、實務應用場景
- 面試前起盤判斷該職位屬文職或武職(適合走開門或杜門類型的工作)。
- 判斷面試官(值符/年干)對自己的態度傾向。

## 五、驗證備註

**書上定義的規則：**
- 開門=文職、杜門=武職 這是固定符號對照表,屬於系統內建定義。

**可驗證的因果宣稱：**
- 「日干旺相無四害+太陰九天生日干 → 求職順利」是可驗證的複合條件命題,可以在資料庫累積多筆求職起盤紀錄,分別記錄「條件是否成立」與「結果是否真的順利」,之後做命中率統計。
- 九星對應人品(天輔文雅、天蓬大惡等)這類「符號→人格特質」的斷語較難驗證,因為人格特質本身主觀性高、難以量化,除非搭配結構化的人格測驗(如大五人格量表)做交叉比對,否則只能停留在主觀印象層次,建議列為「低可驗證性」條目。
