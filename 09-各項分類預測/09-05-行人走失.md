## 一、原文重點整理

### 1. 判斷走失方向與距離
- 找「用神宮位」的方向,就是走失者離開的方向。
- 距離依落宮數計算:例如巽宮就是 1、4、7(表示可能走了 1、4 或 7 個單位的距離,單位可依情境彈性解讀為公里、條街等)。

### 2. 各宮落宮數對照表
| 宮位 | 對應數字 |
|---|---|
| 巽宮 | 1、4、7 |
| 離宮 | 3、6、9 |
| 坤宮 | 2、5、8 |
| 震宮 | 3、6、9 |
| 兌宮 | 1、4、7 |
| 艮宮 | 2、5、8 |
| 坎宮 | 1、4、7 |
| 乾宮 | 3、6、9 |

### 3. 依神煞判斷走多遠
- 用神宮位臨**九天** → 走得遠。
- 臨**九地** → 不會走太遠。
- **伏吟局** → 走得近。
- **反吟局** → 走得遠。
- 臨**馬星** → 走得快（移動速度快）。

### 4. 判斷走失人身邊狀況
根據用神宮內的訊息判斷走失者的性質與狀況,再參考「相鄰兩宮位」推測身邊環境,由預測師分析可能去向並描述環境。

### 5. 長輩/平輩/晚輩區分
年干代表長輩、月干代表平輩、時干代表晚輩。若問測者不特別說明陰陽(性別),就不刻意區分;能區分則區分男女。

### 6. 能否找到人的判斷法(依日干與時干生剋關係)
| 生剋關係 | 判斷結果 |
|---|---|
| 您(日干)剋她時干 | 您能找到她 |
| 她生您或相比 | 她會主動找您 |
| 她剋您 | 可能找不到她 |
| 您生她 | 她也不回來 |

### 7. 車禍肇事者逃逸的尋人應用
若車禍肇事者跑了,無法分清是誰、男是女,可以用「月干宮」代表肇事者來套用同樣的尋人方法。

## 二、關鍵名詞解釋

| 名詞 | 定義 |
|---|---|
| 落宮數 | 各宮位對應的特定數字組合,用於推算距離、時間等數量性質的問題 |
| 九天 | 象徵高遠、向外發展,此節解讀為「走得遠」 |
| 九地 | 象徵沉潛、內斂,此節解讀為「不會走太遠」 |

## 四、驗證備註

> 尋人屬於時間敏感的安全事件。發現兒童、長者、失智者或其他高風險人士失蹤時，應立即聯絡警方、消防或所在地緊急服務，並依官方尋人程序提供照片、衣著、最後位置與健康資訊；不可等待占測結果。

**書上定義的規則：**
- 九天=遠、九地=近、伏吟=近、反吟=遠,這些是系統內建的符號語意,屬於定義而非可驗證命題。

**可驗證的因果宣稱：**
- 「用神落宮方向 = 走失者實際離開方向」與「落宮數 = 實際走失距離」是這節中最具體、最適合驗證的兩條斷語,因為走失者的真實方向與距離最終通常會有客觀答案(找到人之後就知道)。若要驗證,建議記錄:(1) 起盤時間、(2) 預測方向與距離區間、(3) 實際尋獲的方向與距離,累積多筆案例後計算命中率與誤差範圍。
- 「找不找得到人」這條規則(您剋她→找得到;她剋您→找不到)是一個二元判斷,理論上最容易做勝率統計,但要注意:這類民俗尋人法通常只在少數「戲劇性」的成功案例會被記錄流傳(倖存者偏差),失敗的案例可能不會被拿出來討論,建議追蹤時要主動記錄「沒找到」的案例,才能得到未經篩選的真實命中率。
