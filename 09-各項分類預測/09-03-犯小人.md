## 一、原文重點整理

### 1. 看小人對象的層級
| 剋日干的來源 | 代表對象 |
|---|---|
| 年干剋日干 | 老闆打壓 |
| 月干剋日干 | 潛在的小人、同事搞鬼、直屬主管打壓 |
| 時干剋日干 | 部屬在後面私下勾結、結黨營私、不聽指揮 |

### 2. 依神煞判斷小人手法
- 對宮宮位有**玄武**來沖剋日干宮 → 單位內部有小人作祟,暗中搞陰、搞暗的、虛假,引起口舌是非。
- 月干、時干臨**騰蛇**來沖剋日干 → 對方難纏、不好擺脫。
- 月干、時干臨**白虎**來沖剋日干 → 對方強勢、很厲害、名目張膽欺侮您。
- 月干、時干臨**太陰**來沖剋日干 → 對方陰謀虛假,凡事都在暗中搞鬼。
- 月干、時干臨**六合**或**寄宮**來沖剋日干 → 對方糾眾來搞您(霸凌、合夥他人為難您;六合代表集體犯案)。

## 二、關鍵名詞解釋

| 神煞 | 象徵意涵 |
|---|---|
| 玄武 | 暗中、陰謀、盜竊、口舌是非 |
| 騰蛇 | 善變、纏繞、難以擺脫 |
| 白虎 | 強勢、兇猛、公開的傷害 |
| 太陰 | 隱蔽、陰柔、暗中操作(此節作負面解讀,與09-01節中太陰代表「保護/提升」的正面意涵不同,需依落宮生剋關係區分吉凶) |
| 六合 | 集體行動、合夥、團夥性質 |

## 三、實務應用場景
- 作為研究作者如何分類職場人際壓力的文本索引。盤面不能證明某人霸凌、偷竊、勾結或「搞鬼」；真實爭議應保留訊息、日期與證人等可核對資料，依公司申訴、工會、警方或法律程序處理。

## 五、驗證備註

**書上定義的規則：**
- 玄武=暗、騰蛇=纏、白虎=強勢、六合=集體,這是神煞的固定象意表,屬系統內建定義,本身不是「命題」而是「詞彙」。

**可驗證的因果宣稱較弱的一節：**
- 這節內容比起09-01,更偏向「命名/分類」而非「預測後果」——它是在幫你把已發生的困擾「歸因分類」(這是誰在整我、用什麼手法),而不是預測未來會不會發生。這種**事後歸因型**的敘述特別要注意「巴納姆效應」(Barnum effect)的風險:任何模糊的人際困擾描述都可能讓人覺得「說中了」,因為職場小人手法本來就大同小異(暗中搞鬼、強勢欺壓、拉幫結派——這幾乎涵蓋了所有人際衝突的可能形式)。
- 若要驗證,比較好的做法是「事前預測」:起盤時先寫下判斷(例如:此為月干玄武沖剋,應為同事暗中搞鬼),再觀察後續實際發生的狀況是否真的對得上「玄武=暗中」而非「白虎=強勢公開」,如果每次都能提前正確區分「暗的」跟「強勢的」小人類型,才算是有一定的預測力。
