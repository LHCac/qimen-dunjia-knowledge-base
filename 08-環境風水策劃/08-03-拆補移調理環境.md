## 一、四類環境象意來源

原書把環境判讀來源分為八神、十天干、九星及八門。本節主要展開十天干，先列每一干的動物、植物、靜物與地理類別，再示範兩干組合落坎宮時如何推演北方外景與內景。

## 二、十天干核心環境類別

| 天干 | 原書主要聯想範圍（摘要） |
|---|---|
| 甲 | 大樹、粗柱、高大建築、屋樑、貴重物與帶殼事物 |
| 乙 | 花草、藤蔓、小樹、藝術品、傢俱、管線與彎曲形態 |
| 丙 | 光、熱、爐灶、窗戶、紅色、電力與高處 |
| 丁 | 尖刺、燈火、針刀、小型電器、屋簷、屋角與路口 |
| 戊 | 牆、土石、陶瓷、水泥、庭院、客廳、堤防與墳地 |
| 己 | 坑、溝、低窪、陽台、垃圾、食物、繩索與捲曲形態 |
| 庚 | 道路、門窗、金屬、車輛、機械、關卡與大型石材 |
| 辛 | 小型金屬、飾品、顆粒、門窗、小路與電子零件 |
| 壬 | 江河湖海、道路人流、窗簾、水管、浴室及交通場所 |
| 癸 | 濕地、池塘、污水、液體、飲品、下水系統與潮濕處 |

## 三、組合閱讀方式

- 第一個天干提供主要形狀、材質或場景，第二個天干補充顏色、物件或狀態。
- 落宮決定方位；原書以坎宮示範北方，並分成可在屋外觀察的「外景」與室內的「內景」。
- 例如甲配庚被連到大路、鐵塔或貴重金屬；乙配壬被連到彎曲河流、窗簾與藝術門；戊配辛被連到破損牆面、砂石及顆粒；壬配癸被連到混濁河水、髒亂街道與不潔窗戶。
- 原表約有百組，且每組常列多個可能物件。這種高覆蓋率容易產生事後選擇命中項目的偏誤；若要研究準確度，應先登記預測清單，再現場核對命中與未命中。

## 六、整理稿勘誤

- 第三節實際止於書頁 384，不是原稿標示的 383。
- Claude 原表在「己＋丁」後整段錯位，把後續己＋戊至己＋癸依序套到錯誤欄位；本版不沿用該錯位表。
- 原稿把「癸＋己」標為掃描缺漏，但書頁 381-382 可辨識：外景連到垃圾髒水、濕泥坑等，內景連到發酵物、發霉物、廁所或儲物空間。
- 原稿漏掉書頁 383-384 的外景與內景判斷思路，本版已補入索引。
