## 十項環境觀察因素

| 因素 | 原書描述的外形或狀態 | 作者延伸的象意 |
|---|---|---|
| 插 | 樹、柱、電線杆或高大筆直建築 | 視落宮與生剋延伸至家人健康／傷害 |
| 反 | 反弓狀水路或道路 | 視為對被剋宮位不利 |
| 斷 | 道路、河流或樹幹中斷 | 視為事情或運勢受阻 |
| 走 | 水流、道路或氣勢向外流去 | 視為消耗；以所採座標判定影響重點 |
| 射 | 屋簷、屋角、尖狀物直對居所 | 視為沖射與傷害象意 |
| 破 | 物品殘缺、破損、不完整 | 主張破損物會連到耗損，建議清理 |
| 探 | 物件向外凸出一段 | 連到玄武、偷取與消耗象意 |
| 沖 | 低處直線沖來，或對宮不利資訊相對 | 延伸至受傷、精神問題或半途而廢 |
| 迫 | 前後左右建物距離太近 | 表示擁擠與壓迫 |
| 壓 | 四周建物過高 | 表示視覺與空間壓迫 |

原書在「插、反、射、沖」等項目中加入惡性疾病、斷腿、手術、精神疾病等斷語；這些連結沒有醫學證據，不能用於診斷或預測個人健康。若環境確實有尖銳物、墜落物、道路直衝、採光通風不良或逃生困難，應針對可測量風險改善。
