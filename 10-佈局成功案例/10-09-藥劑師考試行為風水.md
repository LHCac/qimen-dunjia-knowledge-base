## 案例一:新加坡藥劑師考試

### 起局資料
- 公暦 2021年2月15日 16:02(農曆2021年1月4日),陽遁7局
- 四柱:辛丑 庚寅 甲午 壬申;時空亡:甲子旬 戌亥空;馬星:寅
- 值符:天柱星;值使:驚門
- 問測人:李太太(母親),遠距問女兒是否能考取新加坡藥劑師執照。

### 原文重點整理

**1. 六親問法原則**
書中特別強調一個核心規則:「只有在看六親時才需要分陰陽」。李太太問女兒考試,月干（庚，代表李太太本人）落巽宮,而看女兒要看「時干」並依陰陽區分——若問的是兒子,則要看癸的落宮。本案時干壬與李太太同陰陽,同樣落離宮(無奇門四害)。

**2. 解盤重點**
- 九天:測考試表示可以考高分(但書中提醒:九天代表可以「及格」,不能直接斷言「一定考高分」)；九天也代表飛機、遠走高飛、國際貿易、往外發展。
- 天芮星:代表學生、學習、考試,對應學科為醫藥、醫學。
- 丙:光明、機會、前景(丙在學科上對應政治類科目)。
- 庚:專業技術能力很強,表示女兒自己準備充分,足以應付這次考試。
- 杜門:一般表示關閉、封閉,在本案解讀為女兒已經閉關準備考試很長一段時間。
- 隱干癸:同樣代表閉門準備考試的意思。

**3. 重要判讀觀念**
書中提出一個重要提醒:「沒有奇門四害不代表全部都好,有四害也不代表全部都不好,要以符號組合去說故事」,不能機械化套用「有四害=凶、無四害=吉」。

**4. 結論與行為風水指導**
結論:女兒已做充分準備,這次考試應該沒問題。因案主遠距、母親女兒都無法親自佈局,黃老師建議做兩件事:
- 考試當天女兒身上帶著「萬能卡」(即代表天芮星的護身卡片,是老師事先給予馬國客戶的通用化解物)。
- 考試前幾天有空時祈請盤面眾神聖護持,唸誦:「恭請九天玄女、九天、壬、丙、庚、天芮星、杜門、癸等眾神聖降駕護持信女○○○參加這次新加坡藥劑師考試能順利過關」,唸誦九次。
- 考試當天穿著:黑色(壬)寬鬆(丙)上衣、白色(庚)裙子或褲子、手上戴綠色或藍色包包(對應杜門,因包包沒打開也象徵杜門封閉之意)。
- 心裡默想著指導老師(「觀師默相」),藉此獲得加持。

### 結果
2021年3月11日12:14,李太太傳來訊息:女兒考取新加坡藥劑師執照。

## 案例二:英國藥劑師考試(接續同一案主)

### 起局資料
- 公暦 2021年3月18日 16:10(農曆2021年2月6日),陽遁1局
- 四柱:辛丑 辛卯 乙丑 甲申;時空亡:甲申旬 午未空;馬星:寅
- 值符:天沖星;值使:傷門
- 情境:女兒同日需遠距參加英國藥劑師考試兩場,分別為下午4:15、晚上8:30。老師以考試當下時間重新起「時空盤」。

### 原文重點整理

**1. 盤局性質**
本盤為「全盤伏吟」,代表不動之象;因問測者(女兒)遠居馬來西亞、無法親自現場佈局,只能透過「行為風水」沖開伏吟盤,讓整個盤局能量啟動、對當事人有利。

**2. 日干乙落離宮解析**
- 太陰:護佑提升,問考試臨太陰,有助於自己。
- 乙:代表機會,問考試對自己有利。
- 天英星:光明、亮麗。
- 景門:前景、光明。
- 隱干丁:絕佳好機會。
- 提醒:午時逢空亡,但時間走到午時後自然「填空」而解消空亡影響。

**3. 第一場考試(4:15,時間落坤宮)**
- 六合:合作,對應考試有好幾個科目要進行。
- 己擊刑:剛開始考試可能心情緊張、受到影響,第一場會比較差；但離火(自己)生坤土,可增加自身能量,只要時間拖過下午五點來到兌宮,情勢就對自己轉為有利。
- 未時空亡:時間走到未時自然填實。
- 結論:兌宮無奇門四害、又是丁的絕佳機會,若時間拖過申時到酉時,第一場考試可以過關。

**4. 第二場考試(8:30,時間落乾宮)**
- 玄武:表示考題多樣性、靈活。
- 癸:表示考題有陷阱。
- 天心星:有管理、掌控能力,表示自己可以掌控這場考試。
- 開門(與天心星同宮):表示可以開心應付這場考試而順利過關。

**5. 兩場考試的行為風水指導**
| | 第一場(4:15,坤宮) | 第二場(8:30,乾宮) |
|---|---|---|
| 手鍊/水晶串 | 水晶串(值符+六合),戴右手,合掉己擊刑 | 黑色水晶串(玄武+癸) |
| 隨身物 | 萬能卡(天芮星+死門) | 萬能卡+開門+天心星 |
| 服裝 | 黃(己)黑(壬)條紋(壬)上衣 | 黑色(癸)衣服 |
| 座向 | 坐考試桌西南方,面向東北方 | 坐考試桌西北方,面向東南方 |
| 心法 | 心裡默想指導老師加持(觀師默相) | 同左 |

### 結果
英國藥劑師考試同樣順利考取,兩場遠距考試均獲成功。

## 關鍵名詞解釋

| 名詞 | 書中定義/意涵 |
|---|---|
| 六親問法分陰陽 | 問測涉及六親關係(如父母問子女)時,需依當事人陰陽性別選取對應天干(如問兒子看癸、問女兒看時干本身) |
| 行為風水 | 無法在事發現場實體佈局時,以案主自身的服裝顏色、配戴物、座向、方位站立、默想指導老師等「行為」來替代實體佈局,催動盤局能量 |
| 觀師默相 | 遠距佈局時,案主心裡默想指導老師的形象,以獲得師父加持的心法 |
| 萬能卡 | 老師發給熟識客戶的通用化解護身卡片,對應盤中吉利符號(如天芮星),供隨身攜帶催旺用 |
| 全盤伏吟 | 盤局符號整體處於「不動」狀態,須靠沖動(換時辰/換宮位/行為風水)才能催動能量發揮效果 |

## 實務應用場景
- 親子遠距問測(尤其跨國、無法當面佈局)的標準處理流程範例。
- 「時空盤」的實際運用:針對特定時間點(如考試時段)另外起局分析。
- 行為風水(顏色、配戴、座向、心法)作為佈局替代方案的完整範例。

## 驗證備註
- **可驗證性分級**:
  - 「時干宮無奇門四害」屬於**可重現的規則判斷**(任何人依同一套起局方法都能得到相同盤面與符號)。
  - 「女兒已充分準備考試」這個結論其實部分來自案主(母親)提供的背景資訊(女兒閉關苦讀),而非單純從盤面「無中生有」推導,這點書中其實隱含了「解盤時融合當事人自述背景」的操作,值得注意——這代表最終判斷準確與否,可能有相當比例來自對案主資訊的合理推論,而非純粹符號系統本身。
  - 「兩場考試皆考取」是單一結果事件,無法排除女兒本身專業能力(庚:專業技術能力很強)才是決定性因素,佈局本身的因果貢獻度無法從單一案例中分離出來。
- 若要日後系統性驗證行為風水的效果,可考慮的做法:蒐集多筆「同樣情境、部分做行為風水/部分不做」的案例做對照,而非僅記錄成功案例(倖存者偏差:書中案例全部是「結果成功」的案例,缺乏對照失敗案例的比例)。
- 書中明確提出的重要方法論提醒值得保留:「沒有奇門四害往好的去想像,有奇門四害往不好的去想像」——這句話本身承認了解盤存在相當程度的**主觀詮釋空間**,是理解此派解盤邏輯時的重要但書。
