## 起局資料
- 公暦 2020年2月5日 6:36(農曆2020年1月12日),陽遁9局
- 四柱:庚子 戊寅 戊寅 乙卯;時空亡:甲寅旬 子丑空;馬星:巳
- 值符:天芮星;值使:死門
- 問測人:黃老師本人(問自己2020整年運勢)

## 原文重點整理

**1. 流年盤的定義與起局時機**
「流年盤」是用來看整年及每個月運勢的專用盤,書中強調:應在「立春早上」或「農曆正月十五日前」開盤,作為當年度第一次開盤,效果最佳。

**2. 流年盤的處理原則**
- 開盤後,若發現當年某個別月份有奇門四害,必須在「前一個月」先化解該四害。
- 也可以把整個流年盤當成一個完整的盤局進行佈局(即案例中示範的「全年通關局」)。

**3. 本盤日干宮解析(坎宮,自身年度基本盤)**
- 日干戊落坎宮,月干戊也落坎宮 → 月令稱當令,月日同宮代表能量強。
- 子雖然空亡，但作者認為庚子年使「子空亡」填實，因此判作當年沒有空亡影響；原文並非以「巳」填實。
- 本宮無奇門四害。解析:
  - 戊:代表錢、與土地有關的行業都適合進行。
  - 己:自己、彎曲(能柔軟進行各種事情),事情會進行順利、沒有敵人;己也代表地產行業、己是預測師。
  - 九天:今年各項事業能展翅飛翔,大有進展。
  - 天英星:正向、光明、亮麗。
  - 驚門:一鳴驚人。
  - 引干辛:創新、革新、機會,代表今年在外面大有機會。

**4. 時干宮解析(坤宮,代表今年接觸的人事物)**
- 乙:機會、彎曲、藝術、美的事物。
- 庚:剛強、硬功夫、權勢。
- 癸入墓:本身坎宮戊,可以把癸合掉,所以癸入墓對整年無傷。
- 天任星:任勞任怨,凡事不要急。
- 杜門:專業知識及能力,不適合在外面張揚露臉,網路行銷很適合。
- 引干丁:最直接的好機會,今年外部有很多絕佳的好機會。

**5. 唯一的缺憾與通關解法**
時干坤土會來剋制自身日干、月干(戊土受坤土比劫但方向上構成克制關係),需要在「乾宮」佈局進行通關,化阻力為助力。

**6. 各月流年盤逐月處理原則**
| 月份 | 判斷與處理 |
|---|---|
| 寅月 | 已過一半就不要處理 |
| 卯月 | 很好,不必處理 |
| 辰巳月 | 壬入墓,但巽宮丁壬合已把入墓合掉,丁本身可解壬四害;仍畫丁奇符貼於巽宮保險,農曆二月中擇吉日貼符 |
| 午月 | 很好,不必處理 |
| 未申月 | 癸入墓,戊癸合,擺一個「胖撲滿」合掉(本身日月干戊已把癸入墓合掉) |
| 酉月 | 景門=門迫,擺一隻羊(午未合)化解 |
| 戌、亥、子月 | 都不必處理 |
| 丑月 | 沒有空亡(庚子年)、庚落艮宮已填實,庚擊刑(乙庚合已合掉),也可擺兔子(乙)加強合掉 |

**7. 全年通關局佈局方法**
原理:坤土生乾金 → 乾金生坎水,依序佈三個宮位:
1. **先佈日干坎宮**:貼整個流年盤,準備紅黃色陶土做的龍龜,放在櫃子最高處。放置吉祥物時,先唸坎宮文字四遍或七遍,再唸「崑崙咒」,然後把吉祥物放上去。
2. **次佈時干坤宮**:買金色的龍,放在水盤上加水,置於櫃子內(對應杜門),程序同上。
3. **再佈通關乾宮**:買紅色丁字型檯燈,放在櫃子最下方(對應九地),檯燈旁邊放一杯水(對應壬),程序同上。

**8. 擇日與收尾**
- 擇日:3月4日午時佈局。
- 佈局後畫四張催動磁場的符錄(事先畫好),用盤子裝水,將四張符燒化。
- 完成整年流年盤的佈局。

### 結果(書中PS)
佈局成功後,黃老師當年七月開辦「職業堪輿師班」,隔年一月再開「道家陰盤奇門遁甲職業班」。

## 關鍵名詞解釋

| 名詞 | 書中定義/意涵 |
|---|---|
| 流年盤 | 用以推算整年及各月運勢的專用起局方式,需於立春或農曆正月十五前開盤 |
| 月令填實 | 空亡地支若恰逢當年地支(如子空亡遇庚子年),視為被「填實」而消解空亡的負面影響 |
| 通關局 | 針對「時干宮剋日干宮/月干宮」的格局,額外增設一個中介宮位佈局,以五行相生化解相剋關係 |
| 全年通關布局 | 三宮連續佈局(日干宮→時干宮→通關宮),依五行相生順序安放吉祥物,搭配唸誦與燒符催動磁場 |

## 實務應用場景
- 個人/企業年度運勢規劃的標準範本,尤其適合搭配「立春開運」的年度習俗操作。
- 「通關局」概念的完整示範:當時干與日干形成相剋關係時的標準化解流程。
- 逐月吉凶速查的實例參考(哪些月份需要提前化解、哪些月份可略過)。

## 驗證備註
- **重要覺察:此案例是作者自己的案例**。由作者本人自證自己方法有效,存在明顯的「自我印證」風險(researcher/practitioner bias)——沒有第三方或獨立驗證者確認「開職業班成功」與佈局之間存在因果關係。開班招生成功與否,更直接受市場需求、招生行銷、老師本身知名度等變數影響,佈局的邊際貢獻難以單獨分離出來檢驗。
- 逐月處理原則(如「已過一半就不處理」「很好不處理」)透露出這套系統帶有相當的**操作彈性與事後合理化空間**——換言之,無論結果如何,系統內部似乎都能找到一套說法自圓其說,這點是評估此類方法論可證偽性(falsifiability)時要特別留意的地方。
- 值得系統性驗證的具體、可操作項目:流年盤逐月判斷(如「辰巳月有壬入墓」)本身是**基於固定命理演算法則的規則陳述**,可以脫離"有沒有效"的問題,單獨驗證「同一組出生資料,不同人起局是否算出相同的月份四害」,這部分屬於演算法一致性檢驗,和"風水佈局是否真的改善運勢"是兩個層次完全不同的問題,不應混為一談。
