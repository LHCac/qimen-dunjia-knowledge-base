## 每份筆記的狀態

| 狀態 | 意義 |
|---|---|
| `待整理` | 只有書目／目錄骨架，尚未取得該節掃描內容 |
| `整理中` | 已有掃描檔或初稿，正在整理 |
| `待複核` | 第一輪逐頁核對完成，等待第二輪檢查 |
| `已完成` | 已完成兩輪核對，可供日後查詢使用 |

`page_range_estimate` 是依本書目錄中相鄰小節的起始頁推估，不代表已逐頁確認。收到該節完整掃描後，才填寫 `verified_page_range`。

## 兩輪驗證流程

1. 收到該節的原始掃描檔與文字整理稿。
2. **第一輪：逐頁文字核對**——檢查人名、專有名詞、數字、時間、標點及段落是否與掃描頁一致。
3. **第二輪：獨立複核**——重新對照頁面，不沿用第一輪判斷，並檢查摘要是否曲解原意或混入未見於原文的內容。
4. 只保留必要短引文；其餘內容改寫為摘要、定義、步驟與個人筆記。
5. 更新 `source_scan`、`verified_page_range`、`verification_passes`、`verified_on` 與 `status`。
6. 同步補充 [`名詞總表`](00-書籍資訊/名詞總表.md) 及 [`資料來源與驗證紀錄`](00-書籍資訊/資料來源與驗證紀錄.md)。

## 使用原則

- `原文重點整理`：用自己的話忠實摘要，不把推測寫成原書主張。
- `關鍵名詞解釋`：保留本書體系內的定義；若有其他流派差異，另行註記。
- `實務應用場景`：記錄作者的使用方式，不等同已經科學驗證。
- `我的筆記／延伸思考`：明確區分原書內容、個人理解與實際驗證結果。
- 涉及疾病、中藥、投資或其他高風險內容時，只作為書籍研究筆記，不作醫療、用藥或投資依據。
- 第 4 章的斷病、環境中藥與儀式內容均按作者體系記錄，不代表經臨床驗證；有病應由合格醫療專業人員診治。
- 第 5-6 章的求財與企業案例不是投資、財務、人資或管理模型；原書百分比與倍數若無測量依據，均標為作者主張。
- 第 7 章不得用盤面指控外遇、預測犯罪或操控伴侶；任何親密接觸須有明確同意，暴力與健康問題應尋求合格專業協助。
- 第 8 章的環境、人物、職業、妊娠與疾病斷語均屬作者術數主張，不是現場事實或因果證據；建築、消防、電氣及環境風險應由合格專業人員評估。
- 第 9 章的走失、財運、投資與陰宅內容只作文本研究；失聯或有立即危險時應先聯絡警方／緊急服務，投資與墓地處置則依合格專業及法規辦理。
- 第 10 章案例中的結果、比例與第三者敘述屬原書個案主張，不代表已獨立驗證；不得據此診斷、投資、指控或干預他人自主權。
- 第 11 章只保留概念索引與研究性摘要；涉及食品、身體、醫療、符咒或儀式的內容，不提供可直接執行的操作指引，也不得在未同意下施作。

建議整理順序：第 1 章理論篇 → 第 2 章符號象意 → 第 3 章取用神 → 其他應用章節與案例。
